# obdiag V3.2.0

## Version information

- Published: March 14, 2025
- Version number: V3.2.0

## New version changes function points

- [New] obdiag adapts to ipv6.

- [New] obdiag adapts to ob-operator.

- [Fix] The compatibility issue of obdiag installation and deployment in debian 11 and above systems.

- [New] `obdiag gather stack` supports collection of arm machines.

- [New] `obdiag check` adds 5 new inspection scenarios, including log stream copy number check, zone status check, host clock check, OceanBase cluster log retention number check, and network packet loss check.

- [New] `obdiag check` supports OBProxy parameter inspection.

- [Fix] `obdiag gather plan_monitor` bug cannot obtain table schema when SQL statements cross databases.
