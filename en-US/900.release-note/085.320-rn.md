# obdiag V3.2.0

## Version information

- Release date: March 14, 2025
- Version: V3.2.0

## Feature updates

- [New] OceanBase Diagnostic Tool (obdiag) V3.2.0 is adapted to IPv6.

- [New] obdiag V3.2.0 is adapted to ob-operator.

- [Optimized] obdiag V3.2.0 fixes the issue of compatibility in deployment on Debian 11 or later.

- [New] The `obdiag gather stack` command can be used to collect stack information of OceanBase clusters running on servers with Arm architecture.

- [New] The `obdiag check` command supports five new inspection scenarios. Specifically, it can be used to check the number of log stream replicas, status of zones, clock of the host, number of log files retained for an OceanBase cluster, and network packet loss.

- [New] The `obdiag check` command can be used to check parameters of OceanBase Database Proxy (ODP).

- [Optimized] obdiag V3.2.0 fixes the issue where the `obdiag gather plan_monitor` command cannot obtain the table schema when an SQL statement involves multiple databases.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V3.2.0 on an OceanBase cluster deployed by using OceanBase Deployer (obd), the version of obd must be V3.2.0 or later. </p>
</main>
