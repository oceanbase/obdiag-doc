# obdiag V2.4.0

## Version information

- Release date: September 3, 2024
- Version: V2.4.0

## Feature updates

- OceanBase Diagnostic Tool (obdiag) V2.4.0 is ready to use out of the box without a configuration file. For more information, see [issue #394](https://github.com/oceanbase/obdiag/pull/394).
- obdiag V2.4.0 supports silent output. For more information, see [issue #415](https://github.com/oceanbase/obdiag/issues/415).
- obdiag V2.4.0 supports index space analysis. For more information, see [issue #229](https://github.com/oceanbase/obdiag/issues/229).
- obdiag V2.4.0 allows you to initialize environment parameters and run commands by using an SSH client with a specified username. For more information, see [issue #379](https://github.com/oceanbase/obdiag/issues/379).
- obdiag V2.4.0 allows you to specify the remote tmp directory for information collection. For more information, see [issue #259](https://github.com/oceanbase/obdiag/issues/259).

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V2.4.0 on an OceanBase cluster deployed by using OceanBase Deployer (obd), the version of obd must be V2.10.0 or later. </p>
</main>
