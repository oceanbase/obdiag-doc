# obdiag V3.4.0

## Version information

- Published: May 15, 2025
- Version number: V3.4.0

## New version changes function points

- [New] Obdiag V3.4.0 adds 17 new inspection items.

- [New] obdiag V3.4.0 adds `obdiag gather dbms_xplan` to support using the DBMS_XPLAN system package to collect SQL performance diagnostic information.

- [New] (Developer side) obdiag V3.4.0 adds a new github workflow to support the automated regression of obdiag functions.
