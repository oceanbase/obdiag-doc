# obdiag V3.5.0

## Version information

- Published: June 20, 2025
- Version number: V3.5.0

## New version changes function points

- [New] Added 10 new inspection items: cluster network card speed is inconsistent, local IP is incorrect, MemStore usage is too high, cluster has no owner, too many sessions, tenant has lock conflict, data disk is full, tenant has holes, insufficient number of log stream copies, reference count leak.

- [New] The `obdiag rca run` command adds a root cause analysis scenario for Unit GC exceptions. For details, see [Root cause analysis scenario: unit gc](../460.rca/479.rca-unit_gc.md).

- [New] `obdiag gather scene run --scene=observer.cpu_high` command adds processlist information collection.

- [Fix] Fixed the issue of inaccurate `DBMS_XPLAN.DISPLAY_CURSOR` in `obdiag gather dbms_xplan` command.

- [Fix] The problem of abnormal time for log collection to obtain text.

- [Fix] Fixed the problem that the report file generated by the `obdiag gather plan_monitor` command was too large, and added statistics expiration verification logic for this command.

- [Change] (Developer side) Development environment upgraded to python >= 3.11.
