# obdiag V2.3.0

## Version information

- Release date: July 24, 2024
- Version: V2.3.0

## Feature updates

- OceanBase Diagnostic Tool (obdiag) V2.3.0 modifies the execution base to support diagnosing an OceanBase cluster deployed in a Kubernetes environment. For more information, see [issue #287](https://github.com/oceanbase/obdiag/issues/287).
- obdiag V2.3.0 supports root cause analysis for  issues related to DDL statements. For more information, see [issue #143](https://github.com/oceanbase/obdiag/issues/143).
- obdiag V2.3.0 provides the basic collection feature tabledump for collecting table schemas, data distribution information, and other information with a few clicks. For more information, see [issue #109](https://github.com/oceanbase/obdiag/issues/109).
- obdiag V2.3.0 provides the parameter/variable comparison feature. For more information, see [issue #217](https://github.com/oceanbase/obdiag/issues/217).
- obdiag V2.3.0 optimizes the SQL Monitor Report. Specifically, the cluster information and table data distribution information are added to the report. For more information, see [issue #275](https://github.com/oceanbase/obdiag/issues/275).

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V2.3.0 on an OceanBase cluster deployed by using OceanBase Deployer (OBD), the version of OBD must be V2.10.0 or later. </p>
</main>
