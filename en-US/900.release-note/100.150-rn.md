# obdiag V1.5.0

## Version information

- Release date: December 14, 2023
- Version: V1.5.0

## Feature updates

- End-to-end diagnostics is supported.
- The telemetry mode is supported.
- Inspection of the version of OceanBase Database Proxy (ODP) is supported.
- Inspection during a stress test using Sysbench is supported.
- Diagnostics of an OceanBase cluster deployed by using the Docker image is supported.
- You can use the system configuration file `inner_config.yml` or a user-defined configuration file for OceanBase Diagnostic Tool (obdiag). You can also specify the configuration file used in a diagnostics task.
- The compilation mode is modified to generate obdiag binaries. The deployment of obdiag no longer depends on a Python environment.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V1.5.0 on an OceanBase cluster deployed by using OceanBase Deployer (OBD), the version of OBD must be V2.5.0 or later. </p>
</main>
