# obdiag V1.5.2

## Version information

- Release date: January 4, 2024
- Version: V1.5.2

## Feature updates

- OceanBase Diagnostic Tool (obdiag) V1.5.2 optimizes some tasks in the `sysbench_free_test_network_speed.yaml` file.
- obdiag V1.5.2 provides inspection items related to abnormal files in the clog directory.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V1.5.2 on an OceanBase cluster deployed by using OceanBase Deployer (OBD), the version of OBD must be V2.5.0 or later. </p>
</main>
