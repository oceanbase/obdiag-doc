# obdiag V3.1.0

## Version information

- Release date: January 22, 2025
- Version: V3.1.0

## Feature updates

- \[New] Added 12 scenarios for the `obdiag display` command, which is used for one-click information display.

- \[New] Added four inspection items.

- \[Optimized] Optimized the `obdiag analyze log` command by supporting the analysis of OceanBase Database crash logs.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V3.1.0 on an OceanBase cluster deployed by using OceanBase Deployer (obd), the version of obd must be V3.1.0 or later. </p>
</main>
