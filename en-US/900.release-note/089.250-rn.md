# obdiag V2.5.0

## Version information

- Published: October 18, 2024
- Version number: V2.5.0

## New version changes function points

- [New] `obdiag display` first-level function, one command displays various information of the OceanBase cluster, assisting users to conveniently and quickly view cluster information through a black screen terminal: [#PR 472](https://github.com/oceanbase/obdiag/pull/472).

- [New] `obdiag gather` supports desensitizing sensitive content of collected OBServer logs according to specified rules: [#issue 374](https://github.com/oceanbase/obdiag/issues/374).

- [New] `obdiag analyze queue` supports analyzing whether there is a backlog of tenant queues in a specified time period through OBServer logs: [#issue 316](https://github.com/oceanbase/obdiag/issues/316).

- [New] `obdiag check` adds host glibc version check item in inspection: [#issue 469](https://github.com/oceanbase/obdiag/issues/469).

- [New] `obdiag check` adds inspection of statistical information collection issues: [#issue 183](https://github.com/oceanbase/obdiag/issues/183).

- [Optimization] Interception of high-risk SQL/high-risk commands when obdiag is running: [#issue 153](https://github.com/oceanbase/obdiag/issues/153).

- [Optimization] `obdiag gather scene run` decouples SSH and SQL collection of scene collection: [#issue 261](https://github.com/oceanbase/obdiag/issues/261).

- [Fix] `obdiag analyze flt_trace` full-link diagnosis is not associated with OBProxy logs: [#issue 382](https://github.com/oceanbase/obdiag/issues/382).
