# obdiag V2.5.0

## Version information

- Release date: October 18, 2024
- Version: V2.5.0

## Feature updates

- \[New] The `obdiag display` command, which is a level-1 feature, is provided to display information about an OceanBase cluster on the CLI. For more information, see [#PR 472](https://github.com/oceanbase/obdiag/pull/472).

- \[New] The `obdiag gather` command is provided to mask sensitive information in collected OBServer node logs based on specified rules. For more information, see [#issue 374](https://github.com/oceanbase/obdiag/issues/374).

- \[New] The `obdiag analyze queue` command is provided to analyze whether any tenant queue is accumulated within the specified period time based on OBServer node logs. For more information, see [#issue 316](https://github.com/oceanbase/obdiag/issues/316).

- \[New] The `obdiag check` command is provided to check the glibc version of the host. For more information, see [#issue 469](https://github.com/oceanbase/obdiag/issues/469).

- \[New] The `obdiag check` command is provided to diagnose statistics collection issues. For more information, see [#issue 183](https://github.com/oceanbase/obdiag/issues/183).

- \[Optimization] obdiag blocks highly risky SQL statements and commands during execution. For more information, see [#issue 153](https://github.com/oceanbase/obdiag/issues/153).

- \[Optimization] When you use the `obdiag gather scene run` command for scenario-based SQL statistics collection, SSH is no longer needed. For more information, see [#issue 261](https://github.com/oceanbase/obdiag/issues/261).

- \[Bug fix] The issue is fixed where end-to-end link diagnostics initiated by running the `obdiag analyze flt_trace` command does not involve associated OceanBase Database Proxy (ODP) logs. For more information, see [#issue 382](https://github.com/oceanbase/obdiag/issues/382).

  <h4>Notice</h4>
  <p>To use obdiag V2.5.0 on an OceanBase cluster deployed by using OceanBase Deployer (obd), the version of obd must be V3.0.0 or later. </p>
