# obdiag V1.6.1

## Version information

- Release date: March 8, 2024
- Version: V1.6.1

## Feature updates

- OceanBase Diagnostic Tool (obdiag) V1.6.1 supports hot updates to automatically upgrade inspection files and collection scenario files.
- obdiag V1.6.1 upgrades the directory structure of the inspection package file. The inspection information is migrated to the `~/.obdiag/check` directory.
- obdiag V1.6.1 supports collecting information related to I/O issues with a few clicks.
- obdiag V1.6.1 resolves the exception in identifying the version of OceanBase Database.
- obdiag V1.6.1 provides more complete basic information in scenario-based collection.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V1.6.1 on an OceanBase cluster deployed by using OceanBase Deployer (obd), the version of obd must be V2.7.0 or later. </p>
</main>
