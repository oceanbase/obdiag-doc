# obdiag V3.6.0

## Version information

- Published: July 31, 2025
- Version number: V3.6.0

## New version changes function points

- [New] obdiag's MCP service can be called by large models. For specific usage documentation, see [obdiag_mcp_server](https://github.com/oceanbase/mcp-oceanbase/blob/main/doc/obdiag_mcp_server.md).

- [New] The new `obdiag gather core` command supports the one-click collection function of core files. For details, please refer to [Core file collection](../400.gather/100.normal/112.gather_core.md).

- [New] The `obdiag gather scene run` command adds the `obproxy.obproxy_parameter` scene, which is used to collect ODP parameters with one click. For details, see [Collect ODP parameter information](../400.gather/200.scenes/261.obproxy_parameter.md).

- [New] obdiag adds Docker image `quay.io/oceanbase/obdiag:latest`.

- [New] obdiag output results support markdown style.

- [New] Added `obdiag tool` first-level command for integrating other tools, and added `obdiag tool crypto_config` command to support encrypting obdiag configuration files. For detailed introduction, please see [Configuration File Encryption](../800.tool/801.crypto_config.md).

- [New] The `obdiag rca run` command adds the root cause analysis scenario of **OceanBase Cluster Replay Card**. For detailed introduction, please refer to [Root Cause Analysis Scenario: OceanBase Cluster Replay Card](../460.rca/480.rca-replay_hold.md).

- [New] The `obdiag rca run` command adds a root cause analysis scenario of **OceanBase cluster memory explosion**. For detailed introduction, please refer to [Root cause analysis scenario: OceanBase cluster memory explosion](../460.rca/481.rca-memory_full.md).

- [New] The `obdiag rca run` command adds a root cause analysis scenario of **OBServer node deletion exception**. For details, please refer to [Root cause analysis scenario: OBServer node deletion exception](../460.rca/482.rca-delete_server_error.md).

- [New] `obdiag check run` adds 8 new inspection items.
