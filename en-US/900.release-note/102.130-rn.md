# obdiag V1.3.0

## Version information

- Release date: October 27, 2023
- Version: V1.3.0

## Feature updates

Analysis of OceanBase Database logs is supported. You can perform log analysis with a few clicks and export the log diagnosis report.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use OceanBase Diagnostic Tool (obdiag) V1.3.0 on an OceanBase cluster deployed by using OceanBase Deployer (obd), the version of obd must be V2.4.0 or later. </p>
</main>
