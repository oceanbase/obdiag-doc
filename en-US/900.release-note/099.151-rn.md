# obdiag V1.5.1

## Version information

- Release date: December 28, 2023
- Version: V1.5.1

## Bug fixes

- Fixed the metric errors of the crond and firewalld services in the inspection items.
- Fixed the issue where the processing time of the `--since` parameter in the `gather` and `analyze` commands is incorrect.
