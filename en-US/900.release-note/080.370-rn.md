# obdiag V3.7.0

## Version information

- Published: September 9, 2025
- Version number: V3.7.0

## New version changes function points

- [New] obdiag-mcp server releases wheel package (supports direct installation with `pip install obdiag-mcp` command). For specific usage documentation, please see [obdiag_mcp_server](https://github.com/oceanbase/mcp-oceanbase/blob/main/doc/obdiag_mcp_server.md).

- [New] `obdiag check run` command adds 2 new inspection items.

- [New] `obdiag gather plan_monitor` command supports collecting plan_monitor reports of PS SQL.

- [Fix] Fixed the problem of missing option of `--config` in `obdiag analyze queue` command.

- [Fix] Fixed several minor issues in root cause analysis scenarios.
