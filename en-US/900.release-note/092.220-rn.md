# obdiag V2.2.0

## Version information

- Release date: June 14, 2024
- Version: V2.2.0

## Feature updates

- OceanBase Diagnostic Tool (obdiag) V2.2.0 supports root cause analysis for the scenario where the clog disk on an OBServer node is full. For more information, see [issue #64](https://github.com/oceanbase/obdiag/issues/64).
- obdiag V2.2.0 supports root cause analysis for issues related to transactions. For more information, see [issue #142](https://github.com/oceanbase/obdiag/issues/142).
- obdiag V2.2.0 supports configuration check for the columnar storage mode of OceanBase Database. For more information, see [issue #233](https://github.com/oceanbase/obdiag/issues/233).
- obdiag V2.2.0 provides the result of the `EXPLAIN EXTEND` statement in the report generated after you run the `gather plan_monitor` command. For more information, see [issue #226](https://github.com/oceanbase/obdiag/issues/226).
- obdiag V2.2.0 resolves the issue related to the path of inspection package files.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V2.2.0 on an OceanBase cluster deployed by using OceanBase Deployer (OBD), the version of OBD must be V2.9.0 or later. </p>
</main>
