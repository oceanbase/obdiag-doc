# obdiag V3.3.0

## Version information

- Release date: April 18, 2025
- Version: V3.3.0

## Feature updates

- [New] OceanBase Diagnostic Tool (obdiag) V3.3.0 supports the Python script plug-in for inspection in complex scenarios.

- [New] obdiag V3.3.0 supports 24 new inspection items.

- [New] obdiag V3.3.0 supports root cause analysis for suspended transactions: `obdiag rca run --scene=suspend_transaction`.

- [New] obdiag V3.3.0 provides statistics analysis capabilities for the `obdiag gather plan_monitor` command.

- [New] obdiag V3.3.0 supports OceanBase Change Data Capture (obcdc) analysis (a feature currently in beta): `obdiag rca run --scene=oms_obcdc --env component_id=xxxxxx`.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V3.3.0 on an OceanBase cluster deployed by using OceanBase Deployer (obd), the version of obd must be V3.2.0 or later. </p>
</main>
