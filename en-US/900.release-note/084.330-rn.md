# obdiag V3.3.0

## Version information

- Published: April 18, 2025
- Version number: V3.3.0

- [New] Added 24 new inspection items.

- [New] Added fault root cause analysis of suspended things scene `obdiag rca run --scene=suspend_transaction`.

- [New] `obdiag gather plan_monitor` adds statistical information result analysis capabilities.

- [New] `obdiag rca run --scene=oms_obcdc --env component_id=xxxxxx`, supports OMS obcdc component analysis scenario (beta).
