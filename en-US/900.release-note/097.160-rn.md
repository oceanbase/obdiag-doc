# obdiag V1.6.0

## Version information

- Release date: January 31, 2024
- Version: V1.6.0

## Feature updates

- OceanBase Diagnostic Tool (obdiag) V1.6.0 supports collecting diagnostics with a few clicks in different scenarios. This version supports 19 default scenarios.

|name                                 |  info_en                        |
|-------------------------------------|---------------------------------|
|other.application_error              |  [application error]            |
|obproxy.restart                      |  [obproxy restart]              |
|observer.backup                      |  [backup problem]               |
|observer.backup_clean                |  [backup clean]                 |
|observer.clog_disk_full              |  [clog disk full]               |
|observer.compaction                  |  [compaction]                   |
|observer.cpu_high                    |  [High CPU]                     |
|observer.delay_of_primary_and_backup |  [delay of primary and backup]  |
|observer.log_archive                 |  [log archive]                  |
|observer.long_transaction            |  [long transaction]             |
|observer.memory                      |  [memory problem]               |
|observer.perf_sql                    |  [SQL performance problem]      |
|observer.recovery                    |  [recovery]                     |
|observer.restart                     |  [restart]                      |
|observer.rootservice_switch          |  [rootservice switch]           |
|observer.sql_err                     |  [SQL execution error]          |
|observer.suspend_transaction         |  [suspend transaction]          |
|observer.unit_data_imbalance         |  [unit data imbalance]          |
|observer.unknown                     |  [unknown problem]              |

- obdiag V1.6.0 supports scenario-based root cause analysis. This version supports three default scenarios.

|name                                 |  info_en                        |
|-------------------------------------|---------------------------------|
| major_hold                          | [root cause analysis of major hold] |
| disconnection                       | [root cause analysis of disconnection] |
| lock_conflict                       | [root cause analysis of lock conflict] |
