# obdiag V2.6.0

## Version information

- Published: November 28, 2024
- Version number: V2.6.0

## New version changes function points

- [New] The `obdiag analyze memory` command generates an html report of memory analysis by analyzing the observer log, making it easy to view the memory consumption curve of each module of each tenant within a specified time range: [#PR 550](https://github.com/oceanbase/obdiag/pull/550).

- [New] `obdiag display` command provides one-click insight adaptation to the OceanBase database V3.

- [New] `obdiag rca run` command has the ability to output root cause analysis reports in multiple formats such as "table", "json", "xml", "yaml", and "html": [#PR 485](https://github.com/oceanbase/obdiag/pull/485).

- [New] Implement obdiag development environment mirroring based on DEV CONTAINER to facilitate developers to co-build obdiag code directly through the mirror: [#PR 500](https://github.com/oceanbase/obdiag/pull/500).

- [Optimization] `obdiag rca run --scene=ddl_disk_full` Command the root cause analysis and optimization of the scenario of insufficient disk space reported during the DDL process to solve the time-consuming problem: [#issue 231](https://github.com/oceanbase/obdiag/issues/231).

- [Optimization] `obdiag gather scene run` commands observer.backup and backup_clean collection scene optimization, support specified tenants to collect diagnostic information: [#issue 397](https://github.com/oceanbase/obdiag/issues/397).

- [Optimization] `obdiag gather log` command log collection is changed to multi-threading, optimizing log collection speed: [#PR 509](https://github.com/oceanbase/obdiag/pull/509).
