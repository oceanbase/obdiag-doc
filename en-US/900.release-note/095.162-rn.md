# obdiag V1.6.2

## Version information

- Release date: March 15, 2024
- Version: V1.6.2

## Feature updates

- OceanBase Diagnostic Tool (obdiag) V1.6.2 no longer collects pstack information after you run `obdiag gather perf`.
- obdiag V1.6.2 supports the collection of OceanBase Database logs in the cpu_high scenario.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>To use obdiag V1.6.2 on an OceanBase cluster deployed by using OceanBase Deployer (OBD), the version of OBD must be V2.7.0 or later. </p>
</main>
