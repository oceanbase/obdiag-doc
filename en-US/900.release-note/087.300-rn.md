# obdiag V3.0.0

## Version information

- Published: December 31, 2024
- Version number: V3.0.0

## New version changes function points

- [New] Support root cause analysis scenario of OMS full migration. For detailed introduction, please refer to [Root cause analysis scenario: OMS full migration exception oms_full_trans](../460.rca/476.rca-oms_full_trans.md).

- [New] Added `dev_helper.sh` script to help build development environment and create test packages.

- [New] Added several inspection items.

- [New] `inner_config` adds the `strict_host_key_checking` option, which is used to control whether to check the public key of the remote host during ssh connection. The default is `0`, which means no checking and can be configured as needed.

- [New] obdiag cannot be executed in the `~/.obdiag` directory and its subdirectories, otherwise an error will be reported.

- [New] The obdiag directory will automatically back up historical scene files when the version is upgraded.

- [Change] Cancel the encryption function of `obdiag gather log` command, and change the packaging format to `tar.gz`.

- [Change] rca environment variable import no longer uses `--input_parameter`, changed to `--env`.

- [Change] The name of the rca-related plug-in script was changed from `_scene.py` to `.py`. Please back up the custom script in time.

- [Optimization] The `obdiag gather log` command is changed to global concurrency, and the default number of concurrency is 3.

- [Optimization] `obdiag gather plan_monitor` command supports collecting ASH report, DBtime and dbms_xplan.display_cursor execution information.

- [Optimization] The result display of one-click diagnosis analysis log is optimized, sorting according to the time sequence of the first occurrence of the error code in the analysis log.
