# Inspection metrics

This topic describes the inspection metrics of OceanBase Diagnostic Tool (obdiag).

## OceanBase Database

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The issue numbers <code>issue #xx</code> mentioned in this topic are those in obdiag. </p>
</main>

For more information, see [issue #385](https://github.com/oceanbase/obdiag/issues/385) in GitHub.                                  |

As a result, the corresponding tenant architecture cannot be refreshed on the server.                                                           |
| cluster        | datafile_next                             | Checks the node parameter `datafile_maxsize`. For more information, see [issue #573](https://github.com/oceanbase/obdiag/issues/573) in GitHub.  |
