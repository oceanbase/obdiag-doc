# Detailed explanation of cluster inspection indicators

This article explains the sources of some obdiag inspection indicators.

<main id="notice" type='explain'>
  <h4>Description</h4>
  <p>The <code>issue #xx</code> mentioned in this section refers to the issue number of the obdiag project. </p>
</main>

## OBProxy check items

| Check item name | Check item description |
|-----------|-----------|
| version.bad_version | Check if the OBProxy version is a deprecated version. Some versions of OBProxy are buggy and their use is not recommended. |
| version.old_version | Check if the OBProxy version is an old version. Some older versions of OBProxy are no longer supported and are not recommended for use. The source can be found on GitHub [issue #1103](https://github.com/oceanbase/obdiag/issues/1103). |
| parameter.request_buffer_length | Check whether the OBProxy parameter request_buffer_length is the default value. |
| parameter.work_thread_num | Check the value of the OBProxy parameter `work_thread_num` to prevent thread exhaustion problems. The source can be found on GitHub [issue #1019](https://github.com/oceanbase/obdiag/issues/1019). |
| parameter.enable_ob_protocol_v2_with_client | Check the OBProxy parameter `enable_ob_protocol_v2_with_client`, and alert if it is enabled. |

### Table check items

| Check item name | Check item description |
|-----------|-----------|
| table.macroblock_utilization_rate_table | Check whether the ratio of the actual data volume to the actual disk usage of all tables in the OceanBase cluster is within a reasonable range. | table.auto_split_error_table | Checks an auto-split-enabled table for shards that should trigger auto-split but do not. This check identifies tables where some shards have reached the auto_part_size threshold but auto-split is not triggered, which may indicate a problem with the auto-split mechanism. |
