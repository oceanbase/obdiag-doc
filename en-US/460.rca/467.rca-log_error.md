# Root cause analysis scenario: log error log_error

## Applicable scenarios

This article is applicable to the scenario where log stream errors are reported in OceanBase database, and is analyzed based on the internal table data and logs of OceanBase database.

Currently, OceanBase database V4.0.0.0 and later versions are supported. When using obdiag, you need to configure the cluster information in the `~/.obdiag/config.yml` file according to your choice, or configure the cluster information through the `--config` option in the command.

<main id="notice" type='notice'>
  <h4>Attention</h4>
  <ul><li>
  <p>Due to the timeliness of internal data, only current data is supported for analysis. </p>
  </li><li>
  <p>Currently, only the scenario where the log stream has no owner is supported. </p>
  </li></ul>
</main>

## Usage example

Configure the analysis scenario. The default execution example is as follows:

```shell
obdiag rca run --scene=log_error 
```
