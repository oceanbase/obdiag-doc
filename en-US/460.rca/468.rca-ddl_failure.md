# ddl_failure

## Scenarios

You can use the `obdiag rca run` command to analyze the `ddl_failure` scenario based on internal table data and logs of OceanBase Database.

OceanBase Database V4.2.1.0 and later are supported for this feature. When you use obdiag commands, you must configure cluster information in the `~/.obdiag/config.yml` file or by specifying `--config` options in the commands.

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <ul><li>
  <p>Internal data is updated in real time. Therefore, obdiag only supports the analysis of current data.</p>
  </li><li>
  <p>At present, obdiag can analyze only the absence of a log stream leader.</p>
  </li></ul>
</main>

## Supported environment variables

|Variable |Required|Data type|Default value|Description          |
|---------|--------|---------|-------------|---------------------|
|tenant_id|Yes     |string   |""           |The ID of the tenant.|
|table_id |Yes     |string   |""           |The ID of the table. |
|tablet_id|Yes     |string   |""           |The ID of the tablet.|

## Examples

Specify the scenario and related information, such as the tenant ID and table ID, in the command.

```shell
 obdiag rca run --scene=ddl_failure --env tenant_id=1001 --env table_id=1311 --env tablet_id=331
```
