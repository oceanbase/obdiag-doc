# Information about the process list in a tenant

This topic describes how to use OceanBase Diagnostic Tool (obdiag) that is independently deployed to display the information about the process list in a tenant in a terminal.

## Syntax

```shell
obdiag display scene run --scene=observer.processlist [options]
```

The following table describes the options.

|Option        |Required|Data type|Default value         |Description                                                                                                                                                                                                                                                                                                         |
|--------------|--------|---------|----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|-c            |No      |string   |`~/.obdiag/config.yml`|The path of the configuration file.                                                                                                                                                                                                                                                                                 |
|--inner_config|No      |string   |Empty                 |The configurations of obdiag.                                                                                                                                                                                                                                                                                       |
|--config      |No      |string   |Empty                 |The configurations of the cluster diagnosed by obdiag, in the format of `--config key1=value1 --config key2=value2`.  <main id="notice" type='explain'><h4>Note</h4><p>For information about the parameters supported by this option, see <a href="../300.obdiag-config-guide.md">Configure obdiag</a>.</p></main>|
|--env         |No      |string   |Empty                 |Additional parameters required for the `obdiag display` command, in the format of `--env tenant_name=test`.                                                                                                                                                                                                       |

## Examples

### Method 1: Use the command out-of-the-box without a configuration file

```shell
# The --env option is passed to specify the connection string of the target tenant for the query.
obdiag display scene run --scene=observer.processlist --env tenant_name=test \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=***
```

### Method 2: Use the command with a configuration file

Before you use this command, make sure that you have configured the login information of the target nodes in the <code>config.yml</code> configuration file of obdiag. For more information, see [Configure obdiag](../300.obdiag-config-guide.md).

```shell
obdiag display scene run --scene=observer.processlist --env tenant_name=test
```
