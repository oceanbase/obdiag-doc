# 根因分析场景：悬挂事务 suspend_transaction

## 适用场景

本文适用于针对悬挂事务的根因分析，基于 OceanBase 数据库内部表数据以及日志进行分析。

目前支持 OceanBase 数据库 V4.0.0.0 及之后的版本。使用 obdiag 时需根据选择在 `~/.obdiag/config.yml` 文件中配置集群信息，或在命令中通过 `--config` 选项配置集群信息。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>由于内部数据存在及时性，所以仅支持对当前时的数据进行分析。</p>
</main>

## 可导入环境变量

| 变量名   | 是否必选 | 数据类型   | 默认值   | 说明        |
|-------|------|--------|-------|-----------|
| since | 否    | string | "30m" | 指定待分析日志的时间段，默认为 `30m` 表示分析过去 30 分钟内的日志。 |
| tenant_name | 否    | string | ""  | 指定待分析的租户名。 |
| tx_id | 否    | string | ""  | 指定待分析的事务 ID，用于分析特定事务。 |

## 使用示例

* 配置分析场景，默认执行

  ```shell
  obdiag rca run --scene=suspend_transaction
  ```

* 配置分析场景，并指定分析过去 40 分钟的日志

  ```shell
  obdiag rca run --scene=suspend_transaction --env since=40m
  ```

* 配置分析场景，并指定租户名

  ```shell
  obdiag rca run --scene=suspend_transaction --env tenant_name=test
  ```

* 配置分析场景，并指定事务 ID 分析特定事务

  ```shell
  obdiag rca run --scene=suspend_transaction --env tx_id=12345
  ```
