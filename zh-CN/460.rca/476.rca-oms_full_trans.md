# 根因分析场景：OMS 全量迁移异常 oms_full_trans

## 适用场景

本文适用于 OMS 全量迁移异常场景。

## 可导入环境变量

| 变量名          | 是否必选 | 数据类型   | 默认值 | 说明                                           |
|--------------|------|--------|-----|----------------------------------------------|
| component_id | 是    | string | ""  | 任务 ID。全量迁移的任务 ID，一般组成为 `{IP 信息}_connector_xxxxxx` |

## 使用示例

配置分析场景，并配置任务 ID 的执行示例如下：

```shell
obdiag rca run --scene=oms_full_trans --env component_id=xxxxxx
```
