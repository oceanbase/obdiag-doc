# 根因分析场景：事务断连场景 transaction_disconnection

## 适用场景
本文适用于针对事务断连场景的根因分析，基于 observer 内部表数据以及日志进行分析。

目前支持 observer 4.0.0.0 及之后的版本。 

obdiag 使用前需要配置 ~/.obdiag/config.yml 或使用 --config 配置集群信息。

由于内部数据存在及时性，所以仅支持对当前时的数据进行分析。



## 可导入环境变量

| 变量名   | 是否必选 | 数据类型   | 默认值   | 说明        |
|-------|------|--------|-------|-----------|
| since | 否    | string | "30m" | 所需日志的分析时间 |


## 使用示例

### 1. 默认执行

```shell
obdiag rca run --scene=transaction_disconnection 
```
