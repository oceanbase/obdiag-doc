# 根因分析场景：建索引执行报错问题排查 index_ddl_error

## 适用场景

本文适用于对于 OceanBase 数据库中建索引执行报错的场景，基于 OceanBase 数据库内部表数据以及日志进行分析。

目前支持 OceanBase 数据库 V4.2.3.0 及之后的版本。使用 obdiag 时需根据选择在 `~/.obdiag/config.yml` 文件中配置集群信息，或在命令中通过 `--config` 选项配置集群信息。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>由于内部数据存在及时性，所以仅支持对当前时的数据进行分析。</p>
</main>

## 可导入环境变量

| 变量名           | 是否必选 | 数据类型   | 默认值 | 说明   |
|---------------|------|--------|-----|------|
| tenant_id     | 是    | string | ""  | 租户名  |
| table_name    | 是    | string | ""  | 表名   |
| database_name | 是    | string | ""  | 数据库名 |
| index_name    | 是    | string | ""  | 索引名  |

## 使用示例

配置分析场景，并指定租户、表等相关信息的执行示例如下：

```shell
obdiag rca run --scene=index_ddl_error --input_parameters='{"tenant_name":"cudb_test","table_name":"test1245","database_name":"test","index_name":"idx_name"}'
```
