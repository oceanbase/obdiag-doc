# 根因分析场景：ddl失败 index_ddl_error

## 适用场景
本文适用于对于 observer 中日志流报错的场景，基于 observer 内部表数据以及日志进行分析。

目前支持 observer 4.2.1.0 及之后的版本。 

obdiag 使用前需要配置 ~/.obdiag/config.yml 或使用 --config 配置集群信息。

由于内部数据存在及时性，所以仅支持对当前时的数据进行分析。

注意：目前仅支持日志流无主的场景。

## 可导入环境变量

| 变量名       | 是否必选 | 数据类型   | 默认值 | 说明          |
|-----------|------|--------|-----|-------------|
| tenant_id | 是    | string | ""  | 租户名         |
| table_id  | 是    | string | ""  | table_id的值  |
| tablet_id | 是    | string | ""  | tablet_id的值 |
 

## 使用示例

### 1. 指定环境变量执行

```shell
obdiag rca run --scene=ddl_failure --input_parameters='{"tenant_id":"1001","table_id":"1311","tablet_id":"331"}'
```
