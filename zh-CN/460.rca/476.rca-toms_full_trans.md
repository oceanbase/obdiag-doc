# 根因分析场景：oms全量迁移异常 transaction_wait_timeout

## 适用场景

本文适用于 oms 全量迁移异常场景。

## 可导入环境变量

| 变量名          | 是否必选 | 数据类型   | 默认值 | 说明                                           |
|--------------|------|--------|-----|----------------------------------------------|
| component_id | 是    | string | ""  | 任务id。全量迁移的任务id，一般组成为 {ip信息}_connector_xxxxxx |

## 使用示例

配置分析场景，并配置错误信息的执行示例如下：

```shell
obdiag rca run --scene=oms_full_trans --env component_id=xxxxxx
```
