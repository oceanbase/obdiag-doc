# 根因分析场景：冻结与转储 freeze_dump

## 适用场景

本文适用于 OceanBase **4.x** 集群在 **minor freeze（转储）/ flush** 路径上出现异常或压力时的根因采集与初步分析。场景会查询 `CDB_OB_FREEZE_INFO`、`__all_virtual_minor_freeze_info`、`__all_virtual_compaction_diagnose_info`、`GV$OB_COMPACTION_SUGGESTIONS`、`GV$OB_COMPACTION_PROGRESS`、租户 memstore 等视图，将结果落盘为 JSON，并结合简单启发式规则给出记录与建议。

适用于：转储长时间不结束、memstore 压力高、合并诊断信息中出现 FAILED/RUNNING 等需要对照内部表与日志进一步排查的情况。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul>
  <li>要求 Observer 版本 <strong>&ge; V4.0.0.0</strong>；低于 4.0 会初始化失败。</li>
  <li>配置文件中的 <code>tenant_sys</code> 用户需具备 <code>oceanbase</code> 库及相关<strong>视图读权限</strong>。</li>
  <li>内部表数据具有时效性，分析反映的是<strong>执行当时</strong>的集群状态。</li>
  </ul>
</main>

## 可导入环境变量

| 变量名 | 是否必选 | 数据类型 | 默认值 | 说明 |
|--------|----------|----------|--------|------|
| tenant_id | 否 | string | 空 | 指定租户 ID 时，仅对该租户过滤查询；不指定则采集全集群（各 SQL 语义以场景实现为准）。 |
| collect_logs | 否 | string/bool | false | 为 `true` / `1` / `yes` / `y` 时，会按内置关键字对 Observer 日志做 grep 收集，结果保存在本次 RCA 目录下的 `freeze_dump_logs/`。 |

## 使用示例

* 默认执行（全租户相关视图采集）

  ```shell
  obdiag rca run --scene=freeze_dump
  ```

* 指定租户

  ```shell
  obdiag rca run --scene=freeze_dump --env tenant_id=1002
  ```

* 同时拉取与转储/minor freeze 相关的 Observer 日志片段

  ```shell
  obdiag rca run --scene=freeze_dump --env tenant_id=1002 --env collect_logs=true
  ```

## 分析内容与产出

执行成功后，在 `--store_dir` 指定目录（默认 `./obdiag_rca/` 下由框架生成的任务路径）中会生成若干 JSON 文件，主要包括（文件名以实际为准）：

* **freeze_info.json**：`CDB_OB_FREEZE_INFO` 冻结相关信息  
* **minor_freeze_info.json**：`__all_virtual_minor_freeze_info` 中处于关注状态的 minor freeze 行  
* **compaction_diagnose.json**：`__all_virtual_compaction_diagnose_info` 中 FAILED/RUNNING 等诊断行  
* **compaction_suggestions.json**：`GV$OB_COMPACTION_SUGGESTIONS`  
* **compaction_progress.json**：`GV$OB_COMPACTION_PROGRESS`  
* **tenant_memstore_info.json**：租户 memstore 使用情况；memstore 使用率较高时会在报告中记录并给出与 freeze/flush 压力相关的提示  

若开启 **collect_logs**，会增加 **freeze_dump_logs/** 目录，内含按关键字 grep 的 Observer 日志片段。

终端/报告中的 **record**、**suggest** 字段会汇总关键发现（如 memstore 使用率阈值、minor freeze/compaction 启发式判断等），便于与 [卡合并 major_hold](463.rca-major_hold.md)、[合并状态展示](../../470.display/637.observer_compaction.md) 等结论对照。
