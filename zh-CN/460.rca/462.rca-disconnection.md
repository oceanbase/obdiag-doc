# 根因分析场景：断链接 disconnection

## 适用场景
本文适用于对于断链接的场景，基于 obproxy 的诊断日志 obproxy_diagnosis.log ，通过分析日志，定位到问题所在。

目前支持 obproxy 4.2.2.0及之后的版本。 obdiag 使用前需要配置 ~/.obdiag/config.yml 或使用 --config 配置集群信息时需要包含obproxy的信息

## 可导入环境变量

| 变量名               | 是否必选 | 数据类型   | 默认值 | 说明                  |
|-------------------|------|--------|-----|---------------------|
| since             | 否    | string | 30m | 指定需要往回追溯的时间，默认为30分钟 |
| max_parses_number | 否    | string | 10  | 最大分析异常场景的数量         |


## 使用示例

### 1. 默认执行：分析30分钟内，分析最多10个异常场景

```shell
obdiag rca run --scene=disconnection
```
### 2. 指定时间：分析1天内的，分析最多10个异常场景
```shell
obdiag rca run --scene=disconnection --input_parameters='{"since":"1d"}'
```

### 3. 指定时间：分析1天内的，分析最多100个异常场景
```shell
obdiag rca run --scene=disconnection --input_parameters='{"since":"1d","max_parses_number":"100"}'
```
