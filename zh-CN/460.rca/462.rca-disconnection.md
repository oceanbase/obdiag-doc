# 根因分析场景：断链接 disconnection

## 适用场景

本文适用于对于断链接的场景，基于 ODP 的诊断日志 `obproxy_diagnosis.log`，通过分析日志定位到问题所在。

目前支持 ODP V4.2.2.0 及之后的版本。使用 obdiag 时需根据选择在 `~/.obdiag/config.yml` 文件中配置集群信息（包含 ODP 信息），或在命令中通过 `--config` 选项配置集群信息（包含 ODP 信息）。

## 可导入环境变量

| 变量名               | 是否必选 | 数据类型   | 默认值 | 说明                  |
|-------------------|------|--------|-----|---------------------|
| since             | 否    | string | 30m | 指定需要往回追溯的时间，默认为 30 分钟 |
| max_parses_number | 否    | string | 10  | 最大分析异常场景的数量         |

## 使用示例

* 默认执行，分析 30 分钟内的断链场景，最多分析 10 个异常场景

  ```shell
  obdiag rca run --scene=disconnection
  ```

* 指定分析一天内的断链场景，最多分析 10 个异常场景

  ```shell
  obdiag rca run --scene=disconnection --env since=1d
  ```

* 指定分析一天内的断链场景，并设置最多分析 100 个异常场景

  ```shell
  obdiag rca run --scene=disconnection --env since=1d --env max_parses_number=100

  ```
