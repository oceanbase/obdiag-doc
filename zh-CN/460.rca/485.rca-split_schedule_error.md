# 根因分析场景：分区分裂调度错误 split_schedule_error

## 适用场景

本文适用于针对分区分裂调度错误的根因分析，基于 OceanBase 数据库内部表数据以及日志进行分析，帮助定位分区分裂调度失败的原因。

使用 obdiag 时需根据选择在 `~/.obdiag/config.yml` 文件中配置集群信息，或在命令中通过 `--config` 选项配置集群信息。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>由于内部表数据存在及时性，所以仅支持对当前时的数据进行分析。</p>
</main>

## 可导入环境变量

| 变量名   | 是否必选 | 数据类型   | 默认值   | 说明        |
|-------|------|--------|-------|-----------|
| tenant_id | 否    | string | ""  | 指定待分析的租户 ID。 |
| table_id | 否    | string | ""  | 指定待分析的表 ID。 |

## 使用示例

* 配置分析场景，默认执行

  ```shell
  obdiag rca run --scene=split_schedule_error
  ```

* 配置分析场景，并指定租户 ID

  ```shell
  obdiag rca run --scene=split_schedule_error --env tenant_id=1001
  ```

* 配置分析场景，并指定表 ID

  ```shell
  obdiag rca run --scene=split_schedule_error --env table_id=500001
  ```

## 分析内容

该场景会分析以下内容：

1. **分裂任务状态**：检查分区分裂任务的执行状态。
2. **调度器状态**：分析分裂调度器的运行状态。
3. **分裂阻塞原因**：分析可能导致分裂调度阻塞的原因。
4. **日志分析**：分析 OceanBase 集群日志中的分裂相关错误信息。

## 输出结果

分析完成后会生成诊断报告，报告中包含：

* 分裂调度错误的根因分析结果
* 问题定位信息
* 修复建议

## 常见原因

分区分裂调度错误的常见原因包括：

* 分裂目标分区已存在。
* 资源不足导致分裂失败。
* 分裂过程中发生了异常。
* 调度器状态异常。

## 解决建议

* 检查分裂任务的状态和错误信息。
* 确认资源（内存、磁盘等）是否充足。
* 如发现调度器异常，可尝试重启相关服务。
* 如确认为 Bug，请升级到修复版本或联系技术支持。
