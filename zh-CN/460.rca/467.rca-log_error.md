# 根因分析场景：日志报错 log_error

## 适用场景

本文适用于对于 OceanBase 数据库中日志流报错的场景，基于 OceanBase 数据库内部表数据以及日志进行分析。

目前支持 OceanBase 数据库 V4.0.0.0 及之后的版本。使用 obdiag 时需根据选择在 `~/.obdiag/config.yml` 文件中配置集群信息，或在命令中通过 `--config` 选项配置集群信息。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul><li>
  <p>由于内部数据存在及时性，所以仅支持对当前时的数据进行分析。</p>
  </li><li>
  <p>目前仅支持分析日志流无主的场景。</p>
  </li></ul>
</main>

## 使用示例

配置分析场景，默认执行示例如下：

```shell
obdiag rca run --scene=log_error 
```
