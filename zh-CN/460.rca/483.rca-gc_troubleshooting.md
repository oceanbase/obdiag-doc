# 根因分析场景：GC 问题排查 gc_troubleshooting

## 适用场景

本文适用于针对 GC（Garbage Collection）问题的根因分析，基于 OceanBase 数据库内部表数据以及日志进行分析，帮助定位 GC 相关问题。

目前支持 OceanBase 数据库 V4.0.0.0 及之后的版本。使用 obdiag 时需根据选择在 `~/.obdiag/config.yml` 文件中配置集群信息，或在命令中通过 `--config` 选项配置集群信息。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>由于内部表数据存在及时性，所以仅支持对当前时的数据进行分析。</p>
</main>

## 可导入环境变量

| 变量名   | 是否必选 | 数据类型   | 默认值   | 说明        |
|-------|------|--------|-------|-----------|
| tenant_id | 否    | string | ""  | 指定待分析的租户 ID。 |

## 使用示例

* 配置分析场景，默认执行

  ```shell
  obdiag rca run --scene=gc_troubleshooting
  ```

* 配置分析场景，并指定租户 ID

  ```shell
  obdiag rca run --scene=gc_troubleshooting --env tenant_id=1001
  ```

## 分析内容

该场景会分析以下内容：

1. **GC 任务状态**：检查当前 GC 任务的执行状态。
2. **GC 阻塞原因**：分析可能导致 GC 阻塞的原因，如长事务、活跃会话等。
3. **资源占用情况**：检查 GC 相关的资源占用情况。
4. **日志分析**：分析 OceanBase 集群日志中的 GC 相关信息。

## 输出结果

分析完成后会生成诊断报告，报告中包含：

* GC 问题的根因分析结果
* 问题定位信息
* 修复建议
