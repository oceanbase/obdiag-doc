# 一键根因分析

本文适用于独立部署 obdiag 的场景，使用 `obdiag rca` 命令可帮助 OceanBase 数据库相关的诊断信息分析，目前支持对 OceanBase 的异常场景进行分析，找出可能导致问题的原因。

如果是 obd 部署的集群，可直接通过 obd 侧诊断命令组对所选集群进行信息收集，详细命令可参考 [诊断工具命令组](https://www.oceanbase.com/docs/community-obd-cn-10000000002049483)。

注：由于根因分析需要大量的内部表数据来进行分析，因此obdiag配置文件中的tenant_sys用户需要有oceanbase库下的表及视图的读权限

## rca 命令组总览

```shell
# 查看已经支持的所有根因分析场景
obdiag rca list 

# 按场景执行根因分分析
obdiag rca run --scene=<scene_name>
```

`scene_name` 包含如下：

* disconnection：断连诊断，基于 OBProxy 诊断日志。
* major_hold：卡合并诊断。
* lock_conflict：锁冲突诊断。
* ddl_disk_full：DDL 过程中磁盘空间不足。
* clog_disk_full：clog 盘满场景根因分析。
* log_error：日志流无主场景根因分析。
* ddl_failure：DDL 失败诊断。
* index_ddl_error：建索引报错根因分析。
* transaction_disconnection：事务断连场景根因分析。
* transaction_execute_timeout：事务执行超时。
* transaction_not_ending：事务不结束场景。
* transaction_other_error：事务其他错误（如错误码 -4030、-4121、-4122、-4124、-4019 等）。
* transaction_rollback：事务回滚报错。
* transaction_wait_timeout：事务等待超时。
* oms_full_trans：OMS 全量迁移异常场景根因分析。
* oms_obcdc：OMS obcdc 组件分析场景根因分析。
* suspend_transaction：悬挂事务根因分析。
* unit_gc：unit GC 问题排查。
* replay_hold：回放卡场景根因分析。
* memory_full：内存爆场景根因分析。
* delete_server_error：删除 OBServer 节点异常场景根因分析。
* gc_troubleshooting：GC 问题排查。
* schema_leak：Schema 泄漏根因分析。
* split_schedule_error：分裂调度异常根因分析。
* weak_read_troubleshooting：弱读问题排查。
* execute_memory_high：SQL 执行内存过高诊断。

## obdiag rca list

使用该命令可以获取根因分析目前支持的场景。

## obdiag rca run

使用该命令可执行指定场景的根因分析。

```shell
obdiag rca run --scene=<scene_name>
```

选项说明如下：

| 选项名 | 是否必选 | 数据类型 | 默认值 | 说明 |
|--------|----------|----------|--------|------|
| --scene | 是 | string | 默认为空 | 根因分析场景名，可通过 `obdiag rca list` 查看支持的场景列表。 |
| --store_dir | 否 | string | `./obdiag_rca/` | 根因分析结果保存路径。 |
| --report_type | 否 | string | table | 报告输出格式，可配置值为 `table`、`json`、`xml`、`yaml`、`html`。 |
| --env | 否 | string | 默认为空 | 场景环境变量，格式：`--env key=value` 或 JSON，可多次指定。具体参见各场景文档。 |
| -c | 否 | string | `~/.obdiag/config.yml` | 配置文件路径。 |
| --inner_config | 否 | string | 默认为空 | obdiag 自用配置，格式：`--inner_config key=value`。 |
| --config | 否 | string | 默认为空 | 集群配置，格式：`--config key1=value1 --config key2=value2`。详见 [obdiag 配置](../300.obdiag-config-guide.md)。 |
| --config_password | 否 | string | 默认为空 | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。详见 [配置文件加密](../800.tool/801.crypto_config.md)。 |

以分析断连的场景为例，命令如下：

```shell
obdiag rca run --scene=disconnection 
```
