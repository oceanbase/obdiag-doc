# 根因分析场景：事务等待超时报错 transaction_not_ending

## 适用场景
本文适用于针对事务执行超时报错的根因分析，基于 observer 内部表数据以及日志进行分析。

目前支持 observer 4.0.0.0 及之后的版本。 

obdiag 使用前需要配置 ~/.obdiag/config.yml 或使用 --config 配置集群信息。

由于内部数据存在及时性，所以仅支持对当前时的数据进行分析。



## 可导入环境变量

| 变量名   | 是否必选 | 数据类型   | 默认值 | 说明                                  |
|-------|------|--------|-----|-------------------------------------|
| phase | 是    | string | ""  | 事务所在阶段，可选 UNSUBMITTED、COMMIT、REPLAY |
| tx_id | 是    | string | ""  | 事务id                                |




## 使用示例

### 1. 默认执行

```shell
obdiag rca run --scene=transaction_not_ending --input_parameters='{"phase":"UNSUBMITTED","tx_id":"0x1"}'
```
