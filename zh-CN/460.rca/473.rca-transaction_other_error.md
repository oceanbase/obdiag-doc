# 根因分析场景：事务其他错误 transaction_other_error

## 适用场景

本文适用于基于事务类错误码的根因分析，目前支持的错误码为 -4030、-4121、-4122、-4124、-4019 ，基于 OceanBase 数据库内部表数据以及日志进行分析。

目前支持 OceanBase 数据库 V4.0.0.0 及之后的版本。使用 obdiag 时需根据选择在 `~/.obdiag/config.yml` 文件中配置集群信息，或在命令中通过 `--config` 选项配置集群信息。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>由于内部数据存在及时性，所以仅支持对当前时的数据进行分析。</p>
</main>

## 可导入环境变量

| 变量名        | 是否必选 | 数据类型   | 默认值 | 说明                                             |
|------------|------|--------|-----|------------------------------------------------|
| error_code | 是    | string | ""  | 错误码，可选 `-4030`、`-4121`、`-4122`、`-4124`、`-4019` |

## 使用示例

配置分析场景，并指定错误码，执行示例如下：

```shell
obdiag rca run --scene=transaction_not_ending --env error_code=-4121
```
