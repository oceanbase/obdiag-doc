# 根因分析场景：事务其他错误 transaction_other_error

## 适用场景
本文适用于事务其他错误的根因分析，除了目前已经列出的错误，比如错误码为：-4030，-4121，-4122，-4124，-4019,基于 observer 内部表数据以及日志进行分析。

目前支持 observer 4.0.0.0 及之后的版本。 

obdiag 使用前需要配置 ~/.obdiag/config.yml 或使用 --config 配置集群信息。

由于内部数据存在及时性，所以仅支持对当前时的数据进行分析。



## 可导入环境变量

| 变量名        | 是否必选 | 数据类型   | 默认值 | 说明                                   |
|------------|------|--------|-----|--------------------------------------|
| error_code | 是    | string | ""  | 错误码，可选 -4030，-4121，-4122，-4124，-4019 |




## 使用示例

### 1. 默认执行

```shell
obdiag rca run --scene=transaction_not_ending --input_parameters='{"error_code":"-4121"}'
```
