# AI 智能诊断助手

obdiag 自 V4.0.0 起支持通过 `obdiag tool ai_assistant` 命令启动 AI 智能诊断助手，本文将介绍具体使用。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该功能为 BETA 版本，需要配置 OpenAI API Key 或兼容接口。</p>
</main>

## 功能介绍

AI 智能诊断助手支持通过自然语言进行诊断交互，用户可以输入诊断需求，助手会自动理解用户意图并调用相应的 obdiag 命令进行诊断。

## 前置配置

使用前需要配置 AI 相关信息，配置文件位于 `~/.obdiag/ai.yml`。

配置示例如下：

```yaml
# AI 配置文件示例
api_key: "your-api-key-here"        # OpenAI API Key 或兼容接口的 Key
api_base: "https://api.openai.com"  # API 地址，可配置为兼容 OpenAI 接口的其他服务
model: "gpt-4"                      # 使用的模型名称
```

## 命令介绍

可在命令后配置 `-h` 选项查看命令帮助：

```shell
obdiag tool ai_assistant -h
```

输出如下：

```shell
Usage: obdiag tool ai_assistant [options]

Options:
  -c CONFIG             config file path
  --config_password=CONFIG_PASSWORD
                        config password
  -h, --help            Show help and exit.
  -v, --verbose         Activate verbose output.
```

选项说明如下：

| 选项名         | 是否必选 | 数据类型   | 默认值      | 说明                                                                                                   |
|-------------|------|--------|----------|------------------------------------------------------------------------------------------------------|
| -c     | 否    | string | `~/.obdiag/config.yml`     | 配置文件路径。      |
| --config_password | 否    | string |  默认为空 | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。              |

## 使用示例

### 启动 AI 助手

```shell
obdiag tool ai_assistant
```

启动后进入交互模式，可以输入自然语言进行诊断交互。

### 交互示例

```shell
$ obdiag tool ai_assistant

Welcome to obdiag AI Assistant (BETA)!
You can ask questions about OceanBase diagnostics in natural language.
Type 'exit' or 'quit' to exit.

> 帮我收集最近 1 小时的日志
AI: 正在执行日志收集...
执行命令: obdiag gather log --since 1h
...

> 检查集群是否有告警
AI: 正在执行集群巡检...
执行命令: obdiag check run
...

> exit
Goodbye!
```

## 注意事项

1. 该功能为 BETA 版本，可能存在不稳定情况。
2. 使用前需要确保已正确配置 `~/.obdiag/ai.yml` 文件。
3. API 调用会产生费用，请注意控制使用量。
4. 敏感信息（如密码）不会发送给 AI 服务。
