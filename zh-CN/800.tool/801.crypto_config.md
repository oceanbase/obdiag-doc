# 配置文件加密

本文是对 obdiag tool crypto_config 命令的介绍。

## 功能介绍

该命令用于对 obdiag 的配置文件进行加密。可以在使用 obdiag 功能时，使用加密后的配置文件，配合 --config_password 选项使用。
加密文件为原路径下生成一个新文件，后缀为 .encrypted。

## 使用方法

查看使用帮助：
```shell
obdiag tool crypto_config -h
Usage: obdiag tool crypto_config [options]

Options:
  --config_password=CONFIG_PASSWORD
                        config password
  --inner_config=INNER_CONFIG
                        change inner config.
  --key=KEY             the key to encrypt or decrypt
  --file=FILE           the file path to encrypt or decrypt
  --encrypted_file=ENCRYPTED_FILE
                        the file path to encrypt
  -h, --help            Show help and exit.
  -v, --verbose         Activate verbose output.
```

## 示例

加密配置文件：
```shell
obdiag tool crypto_config --file ~/.obdiag/config.yml --key=xxx
```
无密码加密配置文件：
```shell
obdiag tool crypto_config --file ~/.obdiag/config.yml
# 后续会有密码询问，需要手动填入
```

解密配置文件，解密成功的配置文件仅进行命令行打印，不会影响其他的文件，也不会保存：
```shell
obdiag tool crypto_config --encrypted_file=~/.obdiag/config.yml.encrypted --key=xxx
```

确认密码是否正确：
```shell
obdiag tool crypto_config --encrypted_file=~/.obdiag/config.yml.encrypted --key=xxx --file=~/.obdiag/config.yml
```

使用加密的配置文件：
```shell
#以巡检为例
obdiag check run  -c ~/.obdiag/config.yml.encrypted --config_password=xxx
```
