# 磁盘 IO 性能检测

obdiag 自 V4.0.0 起支持通过 `obdiag tool io_performance` 命令检测磁盘 IO 性能，本文将介绍具体使用。

## 功能介绍

该命令用于检测 OceanBase 集群各节点的磁盘 IO 性能，支持检测 clog 盘和 data 盘的 IO 性能指标，帮助用户了解磁盘性能状况。

## 注意事项

* 该命令需要 SSH 访问各 OBServer 节点。
* 建议在业务低峰期执行检测，以获取更准确的基线数据。
* 如果 await 值持续较高或 util% 接近 100%，建议检查磁盘性能或考虑扩容。

## 命令介绍

可在命令后配置 `-h` 选项查看命令帮助：

```shell
obdiag tool io_performance -h
```

输出如下：

```shell
Usage: obdiag tool io_performance [options]

Options:
  --disk=DISK           disk type: clog or data
  -c CONFIG             config file path
  --config_password=CONFIG_PASSWORD
                        config password
  --inner_config=INNER_CONFIG
                        change inner config.
  --config=CONFIG       config options
  -h, --help            Show help and exit.
  -v, --verbose         Activate verbose output.
```

选项说明如下：

| 选项名         | 是否必选 | 数据类型   | 默认值      | 说明                                                                                                   |
|-------------|------|--------|----------|------------------------------------------------------------------------------------------------------|
| --disk     | 否    | string | 默认为空     | 磁盘类型，可配置值为 `clog` 或 `data`。      |
| -c | 否    | string |  `~/.obdiag/config.yml` | 配置文件路径。              |
| --config_password | 否    | string |  默认为空 | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。              |
| --inner_config | 否    | string | 默认为空 | obdiag 自用的配置。                     |
| --config | 否    | string | 默认为空 | 需被 obdiag 诊断的集群的配置，固定样式：`--config key1=value1 --config key2=value2`。  <main id="notice" type='explain'><h4>说明</h4><p>支持通过该选项配置的参数可参见 <a href="../300.obdiag-config-guide.md">obdiag 配置</a>。</p></main>                   |

## 使用示例

### 检测 clog 盘 IO 性能

```shell
obdiag tool io_performance --disk=clog
```

输出示例：

```shell
IO Performance Check for clog disk:
+-------------------+--------+--------+--------+--------+
| Node              | await  | r/s    | w/s    | util%  |
+===================+========+========+========+========+
| xxx.xxx.xxx.xxx   | 0.5ms  | 100    | 500    | 15%    |
+-------------------+--------+--------+--------+--------+
| xxx.xxx.xxx.xxx   | 0.8ms  | 120    | 480    | 18%    |
+-------------------+--------+--------+--------+--------+
```

### 检测 data 盘 IO 性能

```shell
obdiag tool io_performance --disk=data
```

输出示例：

```shell
IO Performance Check for data disk:
+-------------------+--------+--------+--------+--------+
| Node              | await  | r/s    | w/s    | util%  |
+===================+========+========+========+========+
| xxx.xxx.xxx.xxx   | 1.2ms  | 200    | 300    | 25%    |
+-------------------+--------+--------+--------+--------+
| xxx.xxx.xxx.xxx   | 1.5ms  | 180    | 320    | 28%    |
+-------------------+--------+--------+--------+--------+
```

### 无配置文件使用

```shell
obdiag tool io_performance --disk=clog \
    --config obcluster.servers.nodes[0].ip=xx.xx.xx.1 \
    --config obcluster.servers.nodes[1].ip=xx.xx.xx.2 \
    --config obcluster.servers.global.ssh_username=test \
    --config obcluster.servers.global.ssh_password=****** \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase
```

## 结果解读

| 指标 | 说明 |
|------|------|
| await | 磁盘 IO 平均等待时间，单位为毫秒（ms）。该值越小，磁盘响应越快。 |
| r/s | 每秒读操作次数。 |
| w/s | 每秒写操作次数。 |
| util% | 磁盘利用率百分比。该值过高（如超过 80%）可能表示磁盘存在性能瓶颈。 |
