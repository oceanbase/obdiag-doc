# 配置校验工具

obdiag 自 V4.0.0 起支持通过 `obdiag tool config_check` 命令校验配置文件中配置的集群的连接状态，本文将介绍具体使用。

## 功能介绍

该命令用于校验 obdiag 配置文件中的数据库连接和 SSH 连接是否正常，帮助用户快速定位连接失败的节点。

## 注意事项

* 建议在执行其他 obdiag 命令前先运行配置校验，确保连接正常。
* 该命令会尝试连接配置文件中的所有节点，可能需要一定时间。
* 如果使用 SSH 密钥认证，请确保密钥文件路径正确且权限设置正确。

## 命令介绍

可在命令后配置 `-h` 选项查看命令帮助：

```shell
obdiag tool config_check -h
```

输出如下：

```shell
Usage: obdiag tool config_check [options]

Options:
  -c CONFIG             config file path
  --config_password=CONFIG_PASSWORD
                        config password
  -h, --help            Show help and exit.
  -v, --verbose         Activate verbose output.
```

选项说明如下：

| 选项名         | 是否必选 | 数据类型   | 默认值      | 说明                                                                                                   |
|-------------|------|--------|----------|------------------------------------------------------------------------------------------------------|
| -c     | 否    | string | `~/.obdiag/config.yml`     | 配置文件路径。      |
| --config_password | 否    | string |  默认为空 | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。              |

## 使用示例

### 校验默认配置文件

```shell
obdiag tool config_check
```

输出示例（连接成功）：

```shell
Config Check Result:
+-------------------+------------------+---------+
| Check Item        | Target           | Status  |
+===================+==================+=========+
| DB Connection     | xx.xx.xx.xx:2881 | Success |
+-------------------+------------------+---------+
| SSH Connection    | xx.xx.xx.xx      | Success |
+-------------------+------------------+---------+
| SSH Connection    | xx.xx.xx.yy      | Success |
+-------------------+------------------+---------+
| SSH Connection    | xx.xx.xx.zz      | Success |
+-------------------+------------------+---------+

All checks passed!
```

输出示例（连接失败）：

```shell
Config Check Result:
+-------------------+------------------+---------+---------------------------+
| Check Item        | Target           | Status  | Error                     |
+===================+==================+=========+===========================+
| DB Connection     | xx.xx.xx.xx:2881 | Failed  | Connection refused        |
+-------------------+------------------+---------+---------------------------+
| SSH Connection    | xx.xx.xx.xx      | Success |                           |
+-------------------+------------------+---------+---------------------------+
| SSH Connection    | xx.xx.xx.yy      | Failed  | Authentication failed     |
+-------------------+------------------+---------+---------------------------+
| SSH Connection    | xx.xx.xx.zz      | Success |                           |
+-------------------+------------------+---------+---------------------------+

Some checks failed! Please fix the configuration.
```

### 校验指定配置文件

```shell
obdiag tool config_check -c /path/to/config.yml
```

### 校验加密配置文件

```shell
obdiag tool config_check -c ~/.obdiag/config.yml.encrypted --config_password=<your_secret_key>
```

## 检查项说明

| 检查项 | 说明 |
|------|------|
| DB Connection | 检查数据库连接是否正常，包括 `db_host`、`db_port`、`tenant_sys.user`、`tenant_sys.password` 等配置。 |
| SSH Connection | 检查各 OBServer 节点的 SSH 连接是否正常，包括 `ip`、`ssh_username`、`ssh_password` 或 `ssh_key_file` 等配置。 |

## 常见错误及解决方案

| 错误信息 | 可能原因 | 解决方案 |
|---------|---------|---------|
| Connection refused | 数据库服务未启动或端口错误 | 检查 OBServer 节点是否正常运行，确认端口配置正确 |
| Authentication failed | 用户名或密码错误 | 检查配置文件中的用户名和密码是否正确 |
| Host unreachable | 网络不通 | 检查网络连接，确认 IP 地址正确 |
| Permission denied | SSH 密钥权限问题 | 检查密钥文件权限，确保权限为 600 |
