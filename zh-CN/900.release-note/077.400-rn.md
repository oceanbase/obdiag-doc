# obdiag V4.0.0

## 版本信息

- 发布时间：2026 年 01 月 07 日
- 版本号：V4.0.0

## 新版本变更功能点

### 新增命令

- 【新增】新增 `obdiag tool ai_assistant` 命令，用于启动 AI 智能诊断助手，支持通过自然语言进行诊断交互。具体介绍可参见 [AI 智能诊断助手](https://www.oceanbase.com/docs/common-obdiag-cn-1000000005508487)。
  
  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>AI 智能诊断助手功能为 BETA 版本，命令使用需要配置 OpenAI API Key 或兼容接口。</p>
  </main>

- 【新增】新增 `obdiag tool io_performance` 命令，用于检测磁盘 IO 性能，支持检测 clog 盘和 data 盘的 IO 性能。具体介绍可参见 [磁盘 IO 性能检测](../800.tool/803.io_performance.md)。

- 【新增】新增 `obdiag tool config_check` 命令，用于校验配置文件中配置的集群的连接状态，支持检查 DB 连接和 SSH 连接状态，可定位具体失败节点。具体介绍可参见 [配置校验工具](../800.tool/804.config_check.md)。

- 【新增】`obdiag display scene run` 命令新增合并状态展示场景，支持展示合并状态、进度、诊断信息和建议。具体介绍可参见 [合并状态展示](../470.display/637.observer_compaction.md)。
  
  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>该场景仅支持 OceanBase 数据库 V4.0.0.0 及以上版本。</p>
  </main>

### 新增 RCA 场景

- 【新增】`obdiag rca run` 命令新增 GC 问题的根因分析场景，具体介绍可参见 [根因分析场景：GC 问题排查 gc_troubleshooting](../460.rca/483.rca-gc_troubleshooting.md)。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>该场景目前仅支持 OceanBase 数据库 V4.0.0.0 及以上版本。</p>
  </main>

- 【新增】`obdiag rca run` 命令新增 Schema 泄漏问题的根因分析场景，具体介绍可参见 [根因分析场景：Schema 泄漏 schema_leak](../460.rca/484.rca-schema_leak.md)。
  
  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>该场景目前仅支持 OceanBase 数据库 V4.0.0.0 及以上版本。</p>
  </main>

- 【新增】`obdiag rca run` 命令新增分区分裂调度错误的根因分析场景，具体介绍可参见 [根因分析场景：分区分裂调度错误 split_schedule_error](../460.rca/485.rca-split_schedule_error.md)。

- 【新增】`obdiag rca run` 命令新增弱读问题的根因分析场景，具体介绍可参见 [根因分析场景：弱读问题排查 weak_read_troubleshooting](../460.rca/486.rca-weak_read_troubleshooting.md)。
  
  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>该场景目前仅支持 OceanBase 数据库 V4.0.0.0 及以上版本。</p>
  </main>

### 功能增强

- 【新增】`obdiag gather log` 和 `obdiag gather obproxy_log` 命令新增 `--recent_count` 选项，支持仅收集最近指定数量的日志文件。

- 【新增】`obdiag gather ash` 命令新增 `--svr_ip`、`--svr_port`、`--tenant_id` 选项，支持按指定条件过滤采样数据。具体介绍可参见 [ASH 报告收集](../400.gather/100.normal/106.gather_ash.md)。
  
  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>新增选项目前仅支持 OceanBase 数据库 V4.3.5.0 及以上版本。</p>
  </main>

- 【新增】`obdiag gather dbms_xplan` 命令新增 `--env` 选项，具体介绍可参见 [DBMS_XPLAN 信息收集](../400.gather/100.normal/111.gather_dbms_xplan.md)。

- 【新增】`obdiag analyze index_space` 命令新增 `--database` 选项，支持指定数据库进行索引空间分析。

- 【新增】`obdiag check run` 命令新增 `deep` 巡检包，用于深度巡检。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>deep 巡检包包含可能影响系统性能的检查任务，生产环境慎用。</p>
  </main>

- 【新增】`obdiag check run` 命令新增 `archive.archive_continuous_error` 巡检项，检查归档连续错误。

- 【优化】悬挂事务（`obdiag rca run --scene=suspend_transaction`）场景支持按租户名（`tenant_name`）和事务 ID（`tx_id`）分析特定事务。

- 【优化】锁冲突（`obdiag rca run --scene=lock_conflict`）场景新增日志分析能力。

- 【优化】卡合并（`obdiag rca run --scene=major_hold`）场景增加重复索引名检测和 DDL 任务状态检查。

- 【优化】事务相关 RCA 场景（`transaction_not_ending`、`transaction_disconnection`、`transaction_execute_timeout`、`transaction_wait_timeout`、`transaction_rollback`、`transaction_other_error`）诊断能力增强。

- 【变更】`obdiag gather plan_monitor`、`obdiag gather scene run` 命令 `--env`选项改为支持多次指定 key=value 格式，例如：`--env host=127.0.0.1 --env port=2881 --env user=test@test --env password=****** --env database=test`。

- 【变更】`obdiag gather log` 命令底层日志搜索算法升级至 v2 版本。

### 依赖变更

- 【变更】新增依赖：`openai>=1.0.0`、`rich>=13.0.0`。

- 【变更】移除依赖：`bcrypt`、`constant`、`protobuf`、`pick`、`subprocess32`、`netifaces`、`zstandard`、`pycryptodome`。

<main id="notice" type='notice'>
  <h4>注意</h4>

</main>
