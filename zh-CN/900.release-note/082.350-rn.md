# obdiag V3.5.0

## 版本信息

- 发布时间：2025 年 06 月 19 日
- 版本号：V3.5.0

## 新版本变更功能点

- 【新增】11个巡检项 (集群网卡速度不一致、local ip 不正确、memstore 使用率过高、集群无主、会话过多、租户存在锁冲突、数据盘满、租户存在空洞、日志流副本数不足、引用计数泄漏)；

- 【新增】obdiag rca run --scene=unit_gc （Unit GC 异常的根因分析场景）；

- 【新增】obdiag gather scene run --scene=observer.cpu_high 新增 processlist 的信息采集

- 【修复】obdiag gather dbms_xplan 中 DBMS_XPLAN.DISPLAY_CURSOR 不准确的问题；

- 【修复】日志收集获取文本时间异常的问题；

- 【修复】obdiag gather plan_minitor 生成的报告文件过大问题以及统计信息过期增加校验逻辑；

- 【变更】(开发者侧) 开发环境升级 python >= 3.11
