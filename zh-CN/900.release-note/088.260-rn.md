# obdiag V2.6.0

## 版本信息

- 发布时间：2024 年 11 月 28 日
- 版本号：V2.6.0

## 新版本变更功能点

- 【新增】`obdiag analyze memory` 命令通过分析 observer 日志生成内存分析的 html 报告，方便查看每个租户在指定时间范围内各个模块的内存消耗曲线: [#PR 550](https://github.com/oceanbase/obdiag/pull/550 )。

- 【新增】`obdiag display` 命令一键洞察适配 OceanBase 数据库 V3.x 集群，同时新增了 2 个洞察场景：[#PR 538](https://github.com/oceanbase/obdiag/pull/538)。

- 【新增】`obdiag rca run` 命令根因分析报告以 "table"、"json"、"xml"、"yaml"、"html" 多种样式输出的能力：[#PR 485](https://github.com/oceanbase/obdiag/pull/485)。

- 【新增】基于 DEV CONTAINER 实现 obdiag 开发环境镜像，方便开发者直接通过镜像进行 obdiag 代码共建：[#PR 500](https://github.com/oceanbase/obdiag/pull/500)。

- 【优化】`obdiag rca run --scene=ddl_disk_full` 命令 DDL 过程中报磁盘空间不足场景根因分析优化，解决耗时长的问题：[#issue 231](https://github.com/oceanbase/obdiag/issues/231)。

- 【优化】`obdiag gather scene run` 命令 observer.backup 和 backup_clean 收集场景优化，支持指定租户进行诊断信息的收集：[#issue 397](https://github.com/oceanbase/obdiag/issues/397)。

- 【优化】`obdiag gather log` 命令日志收集改为多线程，优化日志收集速度：[#PR 509](https://github.com/oceanbase/obdiag/pull/509)。
