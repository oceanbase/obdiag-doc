# obdiag V3.6.0

## 版本信息

- 发布时间：2025 年 07 月 31 日
- 版本号：V3.6.0

## 新版本变更功能点

- 【新增】obdiag 的 MCP 服务可供大模型调用，具体使用文档参见 [obdiag_mcp_server](https://github.com/oceanbase/mcp-oceanbase/blob/main/doc/obdiag_mcp_server.md)。

- 【新增】新增 `obdiag gather core` 命令支持 core 文件一键收集功能，具体介绍可参见 [Core 文件收集](../400.gather/100.normal/112.gather_core.md)。

- 【新增】`obdiag gather scene run` 命令新增 `obproxy.obproxy_parameter` 场景，用于一键收集 ODP 的参数，具体介绍可参见 [收集 ODP 参数信息](../400.gather/200.scenes/261.obproxy_parameter.md)。

- 【新增】obdiag 新增 Docker 镜像 `quay.io/oceanbase/obdiag:latest`。

- 【新增】obdiag 输出结果支持 markdown 样式。

- 【新增】新增 `obdiag tool` 一级命令用于集成其他工具，并新增 `obdiag tool crypto_config` 命令支持将 obdiag 配置文件加密，具体介绍可参见 [配置文件加密](../800.tool/801.crypto_config.md)。

- 【新增】`obdiag rca run` 命令新增 **OceanBase 集群回放卡**的根因分析场景，具体介绍可参见 [根因分析场景：OceanBase 集群回放卡](../460.rca/480.rca-replay_hold.md)。

- 【新增】`obdiag rca run` 命令新增 **OceanBase 集群内存爆**的根因分析场景，具体介绍可参见 [根因分析场景：OceanBase 集群内存爆](../460.rca/481.rca-memory_full.md)。

- 【新增】`obdiag rca run` 命令新增 **OBServer 节点删除异常**的根因分析场景，具体介绍可参见 [根因分析场景：删除 OBServer 节点异常](../460.rca/482.rca-delete_server_error.md)。

- 【新增】`obdiag check run` 新增 8 个巡检项。
