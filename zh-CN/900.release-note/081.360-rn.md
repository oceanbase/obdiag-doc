# obdiag V3.6.0

## 版本信息

- 发布时间：2025 年 07 月 31 日
- 版本号：V3.6.0

## 新版本变更功能点

- 【新增】obdiag 的 MCP 服务可供大模型调用，具体使用文档参见[obdiag_mcp_server](https://github.com/oceanbase/mcp-oceanbase/blob/main/doc/obdiag_mcp_server.md)

- 【新增】`obdiag gather core` 命令新增支持 core 文件一键收集功能；

- 【新增】`obdiag gather scene run --scene=obproxy.obproxy_parameter` 用于一键收集 obproxy 的参数；

- 【新增】obdiag docker 镜像`quay.io/oceanbase/obdiag:latest`；

- 【新增】obdiag 输出结果支持 markdown 样式；

- 【新增】`obdiag tool` 一级命令用于集成其他工具，`obdiag tool crypto_config` 支持 obdiag 配置文件加密；

- 【新增】`obdiag rca run` 命令新增`oceanbase 集群回放卡`的根因分析场景，具体介绍可参见 [根因分析场景：replay_hold](../460.rca/480.rca-replay_hold.md)。

- 【新增】`obdiag rca run` 命令新增`oceanbase 集群内存爆`的根因分析场景，具体介绍可参见 [根因分析场景：memory_full](../460.rca/481.rca-memory_full.md)。

- 【新增】`obdiag rca run` 命令新增`observer 节点删除异常`的根因分析场景，具体介绍可参见 [根因分析场景：delete_server_error](../460.rca/482.rca-delete_server_error.md)。

- 【新增】`obdiag check run` 新增 8 个巡检项。
