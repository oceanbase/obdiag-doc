# obdiag V3.7.0

## 版本信息

- 发布时间：2025 年 09 月 09 日
- 版本号：V3.7.0

## 新版本变更功能点

- 【新增】obdiag-mcp server 发布 wheel 包（支持 `pip install obdiag-mcp` 命令直接安装），具体使用文档请参见 [obdiag_mcp_server](https://github.com/oceanbase/mcp-oceanbase/blob/main/doc/obdiag_mcp_server.md)。

- 【新增】`obdiag check run` 命令新增 2 个巡检项。

- 【新增】`obdiag gather plan_monitor` 命令支持收集 PS SQL 的 plan_monitor 报告。

- 【修复】修复 `obdiag analyze queue` 命令 `--config` 选项缺失的问题。

- 【修复】修复若干根因分析场景的小问题。
