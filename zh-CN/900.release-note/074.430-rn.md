# obdiag V4.3.0

## 版本信息

- 发布时间：2026 年 04 月 14 日
- 版本号：V4.3.0

## 新版本变更功能点

### 新增命令与场景

- 【新增】新增智能诊断 Agent 命令（`obdiag agent`）。Agent 基于 Pydantic-AI 与 MCP，支持自然语言描述诊断需求，并调用 obdiag 的采集、分析、巡检、根因分析等能力。详细介绍可参见 [智能诊断 Agent](../490.obdiag_agent.md)。  
  
  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>obdiag V4.0.x 曾提供的 <code>obdiag tool ai_assistant</code> 已移除，功能统一由 <code>obdiag agent</code> 代替。</p>
  </main>

- 【新增】新增 `obdiag tool sql_syntax` 命令：在已连接的 OceanBase 实例上对**单条** SQL 执行 `EXPLAIN <YOUR_SQL>`，用于校验语法及部分语义问题，**不会执行**原始 DML/DDL 语句本身。具体介绍可参见 [SQL 语法校验工具](../800.tool/805.sql_syntax.md)。

### 功能增强

- 【优化】**集群巡检（check）**：巡检框架持续优化；系统配置 `inner_config.yml` 中 `check.max_workers` 默认调整为 **6**，新增 `check.task_timeout_seconds`（默认 **60** 秒）用于单巡检任务超时控制，可与既有 `check.ssh_manager`（每节点连接池等）配合使用。具体介绍可参见 [obdiag 配置](../300.obdiag-config-guide.md) 与 [一键集群巡检](../360.cluster-monitor/370.use-obiag-check-patrol-oceanbase-database-cluster.md)。

- 【优化】`obdiag gather plan_monitor`：持续改进指定数据库校验与错误提示（V4.2.0 已部分覆盖，本版本继续修复与增强）。具体介绍可参见 [SQL 详情收集](../400.gather/100.normal/103.gather_plan_monitor.md)。

- 【优化】**SQL 审核（analyze sql_review）**：内置规则与实现细节优化，便于离线 SQL 文件审核场景。

### 安装与构建

- 【新增】源码仓库提供 **Debian/Ubuntu 原生打包**支持（`debian/` 目录与 `ubuntu/build_ubuntu.sh`），便于在 Debian 系环境构建/安装；仍可通过 RPM 或 `alien` 转换等方式部署。详见 [obdiag 安装](../200.install-and-deploy-obdiag.md)。

- 【说明】V4.3.0 持续使用 `pyproject.toml` 管理依赖与构建，需确保 Python 版本不低于 V3.11。
