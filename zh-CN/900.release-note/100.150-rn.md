# obdiag V1.5.0

## 版本信息

- 发布时间：2023 年 12 月 14 日
- 版本号：V1.5.0

## 新版本变更功能点
- 新增一键全链路诊断功能
- 新增遥测功能
- 新增 obproxy 的版本巡检功能
- 新增 sysbench 压测进行时的巡检；
- 新增 docker 形态部署的 OceanBase 集群一键诊断功能
- 改造 obdiag 配置文件，拆分为 inner_config.yml 和用户侧配置文件，支持命令行指定配置文件下的一键诊断;
- 改造编译模式，产出 obdiag 二进制，解除对部署环境的 python 依赖。
