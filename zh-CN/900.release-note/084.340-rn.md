# obdiag V3.4.0

## 版本信息

- 发布时间：2025 年 05 月 15 日
- 版本号：V3.4.0

## 新版本变更功能点

- 【新增】新增 17 个巡检项。

- 【新增】`obdiag gather dbms_xplan` 支持使用 DBMS_XPLAN 包收集 SQL 的性能诊断信息。

- 【新增】`obdiag rca run --scene=oms_obcdc --env component_id=xxxxxx`，支持 OMS obcdc 组件分析场景。

- 【新增】（开发者侧） 新增 github workflow 用于支持 obdiag 功能的自动化回归。
