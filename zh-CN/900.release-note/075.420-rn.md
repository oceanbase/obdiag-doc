# obdiag V4.2.0

## 版本信息

- 发布时间：2026 年 03 月 13 日
- 版本号：V4.2.0

## 新版本变更功能点

### 新增命令与场景

- 【新增】`obdiag rca run` 新增 SQL 执行内存根因分析场景（`--scene=execute_memory_high`），支持 OceanBase 数据库 V4.0 及以上版本，可检查 `__all_virtual_memory_info` 中的执行内存、`GV$OB_SQL_WORKAREA_MEMORY_INFO`、内存参数及 Top 消耗 SQL/模块，便于定位执行内存过高问题。具体介绍可参见 [根因分析场景：SQL 执行内存过高](../460.rca/487.rca-execute_memory_high.md)。

- 【新增】`obdiag check run` 部署前环境校验（`--cases=build_before`）新增 docker0 网络接口检查。当通过 OCP 部署 OBProxy 时，若存在 docker0 接口，将提示可能显示 docker0 地址而非实际物理主机地址，便于避免部署配置错误。具体介绍可参见 [一键集群巡检](../360.cluster-monitor/370.use-obiag-check-patrol-oceanbase-database-cluster.md)。

### 功能增强

- 【新增】`obdiag gather perf` 命令支持收集 OBProxy 进程的 perf 性能数据，当配置中存在 OBProxy 节点时，可一并收集 OceanBase 集群与 OBProxy 的 perf 信息；Docker/Kubernetes 环境下的 OBProxy 节点会自动跳过。具体介绍可参见 [火焰图/扁鹊图收集](../400.gather/100.normal/105.gather_perf.md)。

- 【新增】`obdiag gather tabledump` 命令在输出中追加 CREATE TABLE DDL 至 `create_tables_{timestamp}.sql` 文件，便于直接执行建表语句；输出摘要中会包含该 SQL 文件路径。具体介绍可参见 [表相关信息收集](../400.gather/100.normal/107.gather_tabledump.md)。

- 【优化】`obdiag gather plan_monitor` 对解析表进行去重，避免同一表被多次引用时重复处理，提升 schema 报告与统计信息收集效率；同时修复 SQLTableExtractor 逗号连接及无效引用过滤问题。具体介绍可参见 [SQL 详情收集](../400.gather/100.normal/103.gather_plan_monitor.md)。

- 【优化】`obdiag analyze memory` 优化内存分析结果展示样式，改进 HTML 模板缩进与图表参数可读性。具体介绍可参见 [一键诊断分析内存](../450.analyze/507.analyze_memory.md)。

- 【优化】卡合并根因分析场景（`obdiag rca run --scene=major_hold`）新增列组 Schema 问题检查，支持检测异构行列转换场景下 `__all_virtual_column_group_history` 中的旧 `__co_all` 记录，并提供处理步骤。具体介绍可参见 [根因分析场景：卡合并](../460.rca/463.rca-major_hold.md)。

- 【优化】DDL 磁盘满根因分析场景（`obdiag rca run --scene=ddl_disk_full`）支持单条 DDL 中多个索引，`index_name` 参数支持逗号分隔（如 `index_name=idx1,idx2,idx3`），按节点累计各索引预估大小。具体介绍可参见 [根因分析场景：DDL 磁盘满](../460.rca/465.rca-ddl_disk_full.md)。

- 【优化】`obdiag gather plan_monitor` 在指定数据库不存在时增加校验，避免无效连接；错误提示更清晰。

- 【变更】检查框架引入 SSH 连接管理：新增 `inner_config.yml` 中 `check.ssh_manager` 配置（`max_connections_per_node`、`idle_timeout`），实现 `SSHConnectionManager` 连接池，多任务共享每节点 SSH 连接，提升效率与资源管理；巡检任务版本检查逻辑更新，`upper_trans_version` 要求 OceanBase 数据库 V4.0.0.0 及以上版本。具体介绍可参见 [obdiag 配置](../300.obdiag-config-guide.md) 与 [一键集群巡检](../360.cluster-monitor/370.use-obiag-check-patrol-oceanbase-database-cluster.md)。
