# 遥测功能

obdiag的遥测功能默认为开启状态，obdiag执行命令时会采集集群信息、租户信息和巡检执行失败的巡检项名称（不包含结果)

> 使用遥测功能收集数据时会对敏感数据（如 IP）做脱敏处理，主要是为了方便了解用户如何使用 OceanBase 数据库，以及使用过程中可能会遇到什么问题，期望通过这些数据帮助优化obdiag的结构以及改善 OceanBase 数据库。


## 管理遥测命令

您可通过修改 obdiag 的配置文件中的_telemetry变量_控制遥测功能的开启和关闭。
配置文件路径为${obdiag_install_dir}/conf/inner_config.yml
例如下即为关闭遥测功能
```yaml
obdiag:
  basic:
    config_path: ~/.obdiag/config.yml
    config_backup_dir: ~/.obdiag/backup_conf
    file_number_limit: 20
    file_size_limit: 2G
    telemetry: False
    
    
    
*******
******
****

```
## 查看采集数据
您可在~/.obdiag/.obdiag_telemetry.txt 中查看 obdiag 采集的信息内容。
