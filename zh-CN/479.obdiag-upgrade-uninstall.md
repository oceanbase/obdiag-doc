# 更新和卸载
本文将介绍 obdiag 的软件更新以及卸载方法。

## 软件更新

### 方式一：obdiag 独立部署模式更新版本

如果您的 obdiag 是独立部署的，可通过本小节进行更新版本。

- 在线更新(可访问外网的情况下可选择)

    ```bash
    sudo yum update -y oceanbase-diagnostic-tool
    source /opt/oceanbase-diagnostic-tool/init.sh
    ```

    <main id="notice" type='explain'>
      <h4>说明</h4>
      <p> 在线更新的方式支持 centos7/8 暂不支持centos9, 如果是 centos9 请参照下面的离线更新方式。</p>
    </main>

- 离线更新(不可访问外网的情况下可选择)
    OceanBase官网 [下载页](https://www.oceanbase.com/softwarecenter) 下载新版的 OceanBase 数据库定制的敏捷诊断工具（obdiag）。

    ```bash
    yum update -y oceanbase-diagnostic-tool*.rpm
    source /opt/oceanbase-diagnostic-tool/init.sh
    ```

- debian系（如 Ubuntu）更新
    OceanBase官网 [下载页](https://www.oceanbase.com/softwarecenter) 下载新版的 OceanBase 数据库定制的敏捷诊断工具（obdiag）。

    ```bash
    apt-get update
    apt-get install alien -y
    alien --scripts --to-deb  oceanbase-diagnostic-tool*.rpm #转为deb包
    dpkg -i oceanbase-diagnostic-tool*.deb
    source /opt/oceanbase-diagnostic-tool/init.sh
    ```

### 方式二：obd 部署方式更新 obdiag

如果你的待诊断集群是 obd 部署的，建议升级 obd 到 V2.5.0 及以上版本，可通过 obd 的命令直接使用 obdiag 工具，无需配置 ~/.obdiag/config.yml 文件，详细命令可参考 [诊断工具命令组](https://www.oceanbase.com/docs/community-obd-cn-10000000002049483)。

- 在线更新(可访问外网的情况下可选择)

    ```bash
    # 开启 obd 远程镜像拉取模式
    obd mirror enable remote
    # 通过 obd 部署 obdiag 方式来更新
    obd obdiag deploy
    ```

- 离线更新(不可访问外网的情况下可选择)

    OceanBase官网 [下载页](https://www.oceanbase.com/softwarecenter) 下载新版的 OceanBase 数据库定制的敏捷诊断工具（obdiag）。

    ```bash
    # 将离线的 obdiag 包拷贝到 obd 的镜像仓库中
    obd mirror clone oceanbase-diagnostic-tool-xxxxxxxx.rpm
    # 通过 obd 部署 obdiag 方式来更新 obdiag
    obd obdiag deploy
    ```

## 软件卸载
卸载 obdiag 只支持 obdiag 独立部署模式

### obdiag 独立部署模式更新版本

如果您的 obdiag 是独立部署的，可通过本小节进行软件卸载。

    ```bash
    sudo yum remove oceanbase-diagnostic-tool
    sudo rm -rf /opt/oceanbase-diagnostic-tool
    rm -rf ~/.obdiag/
    ```

对于基于 Apt（如 Ubuntu/Debian）且之前通过 alien 转换为 .deb 包安装的系统：

    ```bash
    sudo dpkg -r oceanbase-diagnostic-tool
    sudo rm -rf /opt/oceanbase-diagnostic-tool
    rm -rf ~/.obdiag/
    ```
