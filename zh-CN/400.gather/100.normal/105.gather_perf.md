# 火焰图/扁鹊图收集

本文适用于独立部署 obdiag 的场景，使用 obdiag gather perf 命令可以一键收集所属 OceanBase 集群的 perf 信息(火焰图/扁鹊图)。

如果是 obd 部署的集群，可直接通过 obd 侧诊断命令组对所选集群进行信息收集，详细命令可参考 [诊断工具命令组](https://www.oceanbase.com/docs/community-obd-cn-10000000002049483)。

# 使用说明

需要确保已经在 obdiag 配置文件 <code>config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见[obdiag 配置](../../300.obdiag-config-guide.md)

```shell
obdiag gather perf  [options]
```

选项说明如下：

| 选项名                 | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| --scope    | 否    | string | all               | 用于选择性地收集指定的 perf 信息，可配置值为：`sample`、`flame`、`all`。  |
| --store_dir   | 否    | string |   默认为命令执行的当前路径              | 存储结果的本地路径。 |
| -c | 否    | string |   `~/.obdiag/config.yml `           | 配置文件路径     |
