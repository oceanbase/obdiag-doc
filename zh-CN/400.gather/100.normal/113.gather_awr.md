# AWR 报告收集

本文适用于独立部署 obdiag 的场景，使用 `obdiag gather awr` 命令可一键收集 OceanBase 的 AWR（Active Workload Repository）报告。

若是 OBD 部署的集群，可直接通过 OBD 侧诊断命令组对所选集群进行信息收集，详见 [诊断工具命令组](https://www.oceanbase.com/docs/common-obd-cn-1000000004376513)。

<main id="notice" type='notice'>
  <h4>说明</h4>
  <p><strong>AWR 报告收集依赖企业版 OCP</strong>。使用前请在 obdiag 用户配置中填写 OCP 的登录信息（<code>ocp.login.url</code>、<code>ocp.login.user</code>、<code>ocp.login.password</code>），并确保 OCP 已纳管待诊断的 OceanBase 集群。</p>
</main>

## 使用说明

```shell
obdiag gather awr [options]
```

选项说明如下：

| 选项名 | 是否必选 | 数据类型 | 默认值 | 说明 |
|--------|----------|----------|--------|------|
| --cluster_name | 否 | string | 默认为空 | OCP 中的集群名称，用于指定要采集 AWR 的集群。 |
| --cluster_id | 否 | string | 默认为空 | OCP 中的集群 ID，与 cluster_name 二选一或配合使用。 |
| --from | 否 | string | 默认为空 | AWR 报告时间范围起点，格式：`yyyy-mm-dd hh:mm:ss`。 |
| --to | 否 | string | 默认为空 | AWR 报告时间范围终点，格式：`yyyy-mm-dd hh:mm:ss`。 |
| --since | 否 | string | `30m` | 相对当前时间的时间范围，格式：`<n><m\|h\|d>`，如 `1h` 表示最近 1 小时。 |
| --store_dir | 否 | string | 当前目录 | 存储结果的本地路径。 |
| -c | 否 | string | `~/.obdiag/config.yml` | 配置文件路径。 |
| --inner_config | 否 | string | 默认为空 | obdiag 自用配置，格式：`--inner_config key=value`。 |
| --config | 否 | string | 默认为空 | 集群/OCP 配置，格式：`--config key1=value1 --config key2=value2`。详见 [obdiag 配置](../../300.obdiag-config-guide.md)。 |
| --config_password | 否 | string | 默认为空 | 使用加密配置文件时的密码。详见 [配置文件加密](../../800.tool/801.crypto_config.md)。 |

## 前提条件

1. 已安装 obdiag，并完成用户侧配置。
2. 配置文件中已正确填写 **OCP 登录信息**（`ocp.login.url`、`ocp.login.user`、`ocp.login.password`）。
3. OCP 已纳管待采集 AWR 的 OceanBase 集群，且该集群在 OCP 中可正常访问。

## 使用示例

### 方式一：有配置文件使用（推荐）

确保 `~/.obdiag/config.yml` 中已配置 OCP 及 obcluster 信息后，执行：

```shell
# 收集最近 30 分钟的 AWR 报告（默认）
obdiag gather awr

# 收集最近 1 小时的 AWR 报告
obdiag gather awr --since 1h

# 指定时间范围
obdiag gather awr --from "2024-01-15 10:00:00" --to "2024-01-15 11:00:00"

# 指定 OCP 中的集群名并指定存储目录
obdiag gather awr --cluster_name my_ob_cluster --store_dir ./awr_reports
```

### 方式二：通过 --config 传递配置（开箱即用）

未使用默认配置文件时，可通过 `--config` 传递 OCP 及集群信息（需包含 OCP 登录信息与集群标识）：

```shell
obdiag gather awr --since 1h \
    --config ocp.login.url=http://ocp.example.com:8080 \
    --config ocp.login.user=admin \
    --config ocp.login.password=****** \
    --config db_host=xx.xx.xx.xx \
    --config db_port=2881 \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=****** \
    --config obcluster.servers.global.ssh_username=admin \
    --config obcluster.servers.global.ssh_password=****** \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase
```

## 结果说明

命令执行成功后，会在 `--store_dir` 指定的目录下生成采集包（如 `obdiag_gather_pack_yyyyMMddHHmmss`），其中包含从 OCP 拉取的 AWR 报告文件，可用于性能分析与故障排查。

## 常见问题

- **报错提示 OCP 连接失败**：请检查配置中 `ocp.login.url`、`ocp.login.user`、`ocp.login.password` 是否正确，以及当前网络是否能访问 OCP。
- **报错提示未找到集群**：请确认 `--cluster_name` 或 `--cluster_id` 与 OCP 中纳管的集群一致；若配置中仅有一个集群，可不指定，obdiag 会使用配置中的集群信息。
