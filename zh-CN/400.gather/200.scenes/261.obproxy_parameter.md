# 收集 ODP 参数信息

本文适用于独立部署 obdiag 的场景，可以一键执行将 ODP 参数收集。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p><code>obproxy.obproxy_parameter</code> 场景自 obdiag V3.6.0 起新增。</p>
</main>

## 使用说明

```shell script
obdiag gather scene run --scene=obproxy.obproxy_parameter [options]
```

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| --scene | 是    | string | 默认为空                | 场景名，可以通过 `obdiag gather scene list` 查看当前版本支持哪些场景。  |
| --store_dir | 否    | string |   默认为命令执行的当前路径              | 存储结果的本地路径。 |
| -c | 否    | string |   `~/.obdiag/config.yml`           | 配置文件路径。     |
| --inner_config | 否    | string |   默认为空           | obdiag 自用的配置。固定样式：`--inner_config key1=value1 --inner_config key2=value2`。  <main id="notice" type='explain'><h4>说明</h4><p>支持通过该选项配置的参数可参见 <a href="../../300.obdiag-config-guide.md">obdiag 配置</a> 中 <b>系统配置文件（obdiag 自用的配置）</b> 部分。</p></main>     |
| --config | 否    | string |   默认为空           | 需被 obdiag 诊断的集群的配置，固定样式：`--config key1=value1 --config key2=value2`。  <main id="notice" type='explain'><h4>说明</h4><p>支持通过该选项配置的参数可参见 <a href="../../300.obdiag-config-guide.md">obdiag 配置</a> 中 <b>用户侧配置文件</b> 部分。</p></main>      |
| --config_password     | 否    | string | 默认为空     | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。 <main id="notice" type='explain'><h4>说明</h4><p>详情可参见 <a href="../../800.tool/801.crypto_config.md">配置文件加密</a>。</p></main>      |

## 使用示例

### 方式一：无配置文件使用（开箱即用）

```shell
# ODP 参数信息收集，默认不添加任何参数的情况下收集最近 30 分钟的信息
obdiag gather scene run --scene=obproxy.obproxy_parameter \
    --config obproxy.servers.nodes[0].ip=xx.xx.xx.1 \
    --config obproxy.servers.nodes[1].ip=xx.xx.xx.2 \
    --config obproxy.servers.nodes[2].ip=xx.xx.xx.3 \
    --config obproxy.servers.global.home_path=/home/admin/obproxy
```

### 方式二：有配置文件使用

需要确保已经在 obdiag 配置文件（默认路径 <code>~/.obdiag/config.yml</code>）中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 [obdiag 配置](../../300.obdiag-config-guide.md)。

```shell
# obproxy 参数一键收集
obdiag gather scene run --scene=obproxy.obproxy_parameter
```

## 结果解读

命令执行后会在指定目录下会生成一个文件夹，文件夹形如 `obdiag_gather_pack_xxxxx`，文件夹内存在记录 ODP 参数的文件。

```shell
sql_result.txt # obproxy 参数
```
