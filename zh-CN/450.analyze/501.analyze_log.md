# 一键诊断分析日志

本文适用于独立部署 obdiag 的场景，使用 `obdiag analyze log` 命令可对 OceanBase 的日志进行分析，找出发生过的错误信息。

如果是 obd 部署的集群，可直接通过 obd 侧诊断命令组对所选集群进行信息收集，详细命令可参考 [诊断工具命令组](https://www.oceanbase.com/docs/community-obd-cn-10000000002049483)。

## 使用说明

```shell
obdiag analyze log [options]
```

使用该命令可以一键在线分析 OceanBase 集群的日志，或者通过 `--files` 开启离线分析模式。

选项说明如下：

| 选项名 | 是否必选 | 数据类型 | 默认值 | 说明 |
|--------|----------|----------|--------|------|
| --from | 否 | string | 默认为空 | 分析时间范围起点，格式：`yyyy-mm-dd hh:mm:ss`。 |
| --to | 否 | string | 默认为空 | 分析时间范围终点，格式：`yyyy-mm-dd hh:mm:ss`。 |
| --since | 否 | string | `30m` | 相对当前时间的时间范围，格式：`<n><m|h|d>`，其中，n 表示待输入的时间数字，m 表示分钟，h 表示小时，d 表示天，如 `1h` 表示最近 1 小时。 |
| --scope | 否 | string | all | 要分析的日志类型，可选值为 `observer`、`election`、`rootservice`、`all`。 |
| --grep | 否 | string | 默认为空 | 关键字过滤，可多次指定。 |
| --log_level | 否 | string | 默认为空 | 仅分析不低于该等级的日志。可配置值为 `DEBUG`、`TRACE`、`INFO`、`WDIAG`、`WARN`、`EDIAG`、`ERROR`。 |
| --files | 否 | string | 默认为空 | 离线分析模式时，指定本地日志文件或目录；指定后忽略 `--from`、`--to`、`--since`，从本地文件分析。 |
| --store_dir | 否 | string | 当前目录 | 分析结果存储路径。 |
| --temp_dir | 否 | string | `/tmp` | 在线分析时远端节点临时文件存储目录。 |
| --tenant_id | 否 | string | 默认为空 | 按租户过滤错误统计。可填租户名或 `tenant_id:xxx`（如 `tenant_id:1001`）；不填则统计所有租户。 |
| -c | 否 | string | `~/.obdiag/config.yml` | 配置文件路径。 |
| --inner_config | 否 | string | 默认为空 | obdiag 自用配置，格式：`--inner_config key=value`。 |
| --config | 否 | string | 默认为空 | 集群配置，格式：`--config key1=value1 --config key2=value2`。详见 [obdiag 配置](../300.obdiag-config-guide.md)。 |
| --config_password | 否 | string | 默认为空 | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。详见 [配置文件加密](../800.tool/801.crypto_config.md)。 |

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li>本文所指的在线分析指的是 OceanBase 集群在线运行状态，日志分布在各个 OBServer 节点上。</li>
  <li>本文所指的离线分析模式是 <code>--files</code> 参数传递下，可以分析已经收集到 obdiag 部署机器上的 OBServer 日志。</li></ul>
</main>

## 使用示例

### 方式一：无配置文件使用（开箱即用）

* 在线分析日志示例：

  ```shell script
  obdiag analyze log --from "2023-10-08 10:25:00" --to "2023-10-08 11:30:00" \
    --config obcluster.servers.nodes[0].ip=xx.xx.xx.1 \
    --config obcluster.servers.nodes[1].ip=xx.xx.xx.2 \
    --config obcluster.servers.global.ssh_username=test \
    --config obcluster.servers.global.ssh_password=****** \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase
  ```

* 快捷分析最近一段时间的日志：

  ```shell
  # 在线分析最近一小时的日志，该指令执行的时候会从远程主机上拉取最近一小时的日志进行分析，诊断出出现过的错误
  obdiag analyze log --since 1h \
    --config obcluster.servers.nodes[0].ip=xx.xx.xx.1 \
    --config obcluster.servers.nodes[1].ip=xx.xx.xx.2 \
    --config obcluster.servers.nodes[2].ip=xx.xx.xx.3 \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase

  # 在线分析最近一小时的日志，该指令执行的时候会从远程主机上拉取最近一小时的日志进行分析，诊断出出现过的错误
  # 提供 sys 租户的连接信息，让 obdiag 自动帮你获取集群各节点的 ip 地址
  obdiag analyze log --since 1h \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=*** \
    --config obcluster.servers.global.ssh_username=test \
    --config obcluster.servers.global.ssh_password=****** \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase


  # 在线分析最近 30 分钟的日志，该指令执行的时候会从远程主机上拉取最近30分钟的日志进行分析，诊断出出现过的错误
  # 提供 sys 租户的连接信息，让 obdiag 自动帮你获取集群各节点的 ip 地址
  obdiag analyze log --since 30m \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=*** \
    --config obcluster.servers.global.ssh_username=test \
    --config obcluster.servers.global.ssh_password=****** \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase
  ```

* 按租户过滤错误统计（仅显示指定租户的错误）：

  ```shell
  # 按租户名过滤（在线分析）
  obdiag analyze log --since 1h --tenant_id my_tenant

  # 按租户 ID 过滤（格式：tenant_id:xxx）
  obdiag analyze log --since 1h --tenant_id tenant_id:1001

  # 离线分析时也可按租户过滤
  obdiag analyze log --files test/ --tenant_id tenant_id:1001
  ```

### 方式二：有配置文件使用

需要确保已经在 obdiag 配置文件 <code>~/.obdiag/config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 [obdiag 配置](../300.obdiag-config-guide.md)。。

* 在线分析日志示例：

  ```shell script
  obdiag analyze log --from "2023-10-08 10:25:00" --to "2023-10-08 11:30:00"
  ```

* 快捷分析最近一段时间的日志：

  ```shell
  # 在线分析最近一小时的日志，该指令执行的时候会从远程主机上拉取最近一小时的日志进行分析，诊断出出现过的错误
  obdiag analyze log --since 1h


  # 在线分析最近 30 分钟的日志，该指令执行的时候会从远程主机上拉取最近30分钟的日志进行分析，诊断出出现过的错误
  obdiag analyze log --since 30m
  ```

* 离线分析指定 observer 日志：

  ```shell
  # 离线分析指定的日志文件
  obdiag analyze log --files observer.log.20230831142211247 
  ```
