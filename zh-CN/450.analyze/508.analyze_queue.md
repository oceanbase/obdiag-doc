# 一键诊断分析队列积压

本文适用于独立部署 obdiag 的场景，使用 `obdiag analyze queue` 命令可对 OceanBase 集群的日志进行分析，基于日志中打印的内存信息生成队列积压分析报告。

如果是 obd 部署的集群，可直接通过 obd 侧诊断命令组对所选集群进行分析，详细命令可参考 [诊断工具命令组](https://www.oceanbase.com/docs/community-obd-cn-10000000002049483)。

## 使用说明

```shell
obdiag analyze queue [options]
```

使用该命令可以一键在线分析 OceanBase 集群的日志，基于日志中打印的队列信息分析是否存在队列积压。

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| --tenant | 是    | string | 默认为空              | 指定需要分析的租户名。 |
| --from | 否    | string | 默认为空         | 日志收集的开始时间，格式为: `yyyy-mm-dd hh:mm:ss`。 <main id="notice" type='explain'><h4>说明</h4><p>若使用的 obdiag 为 V2.0.0 之前版本，配置该选项时无需加引号，否则会报错。V2.0.0 及之后版本不再限制配置该选项时是否加引号。</p></main> |
| --to   | 否    | string | 默认为空        | 日志收集的结束时间，格式为: `yyyy-mm-dd hh:mm:ss`。<main id="notice" type='explain'><h4>说明</h4><p>若使用的 obdiag 为 V2.0.0 之前版本，配置该选项时无需加引号，否则会报错。V2.0.0 及之后版本不再限制配置该选项时是否加引号。</p></main> |
| --since  | 否    | string | `30m`        | 分析最近的某段时间，格式为: `<n><m|h|d>`，如 `30m` 表示最近 30 分钟。  |
| --store_dir | 否    | string |   默认为命令执行的当前路径              | 存储结果的本地路径。 |
| --temp_dir     | 否    | string | `/tmp`                  | 远端节点在日志收集过程中产生的临时文件存储目录。                                                                        |
| --queue | 否    | int | 默认为 50              | 队列积压的阈值。 |
| -c | 否    | string |   `~/.obdiag/config.yml`           | 配置文件路径。     |
| --inner_config | 否    | string |   默认为空           | obdiag 自用的配置。     |
| --config | 否    | string |   默认为空           | 需被 obdiag 诊断的集群的配置，固定样式：`--config key1=value1 --config key2=value2`。  <main id="notice" type='explain'><h4>说明</h4><p>支持通过该选项配置的参数可参见 <a href="../300.obdiag-config-guide.md">obdiag 配置</a>。</p></main>     |
| --config_password     | 否    | string | 默认为空     | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。 <main id="notice" type='explain'><h4>说明</h4><p>详情可参见 <a href="../800.tool/801.crypto_config.md">配置文件加密</a>。</p></main>      |

## 使用示例

### 方式一：无配置文件使用（开箱即用）

* 在线分析日志示例：

  ```shell script
  obdiag analyze queue --tenant=sys --from "2023-10-08 10:25:00" --to "2023-10-08 11:30:00" \
    --config obcluster.servers.nodes[0].ip=xx.xx.xx.1 \
    --config obcluster.servers.nodes[1].ip=xx.xx.xx.2 \
    --config obcluster.servers.global.ssh_username=test \
    --config obcluster.servers.global.ssh_password=****** \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase
  ```

* 快捷分析最近一段时间的日志：

  ```shell
  # 在线分析最近一小时的日志，该指令执行的时候会从远程主机上拉取最近一小时的日志进行队列积压分析
  obdiag analyze queue --tenant=sys --since 1h \
    --config obcluster.servers.nodes[0].ip=xx.xx.xx.1 \
    --config obcluster.servers.nodes[1].ip=xx.xx.xx.2 \
    --config obcluster.servers.nodes[2].ip=xx.xx.xx.3 \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase

  # 在线分析最近一小时的日志，该指令执行的时候会从远程主机上拉取最近一小时的日志进行队列积压分析
  # 提供 sys 租户的连接信息，让 obdiag 自动帮你获取集群各节点的 IP 地址
  obdiag analyze queue --tenant=sys --since 1h \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=*** \
    --config obcluster.servers.global.ssh_username=test \
    --config obcluster.servers.global.ssh_password=****** \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase


  # 在线分析最近 30 分钟的日志，生成队列积压分析报告
  # 提供 sys 租户的连接信息，让 obdiag 自动帮你获取集群各节点的 IP 地址
  obdiag analyze queue --tenant=sys --since 30m \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=*** \
    --config obcluster.servers.global.ssh_username=test \
    --config obcluster.servers.global.ssh_password=****** \
    --config obcluster.servers.global.home_path=/home/admin/oceanbase
  ```

### 方式二：有配置文件使用

需要确保已经在 obdiag 配置文件 <code>~/.obdiag/config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 [obdiag 配置](../300.obdiag-config-guide.md)。

* 在线分析日志示例：

  ```shell script
  obdiag analyze queue --tenant=testA --from "2023-10-08 10:25:00" --to "2023-10-08 11:30:00"
  ```

* 快捷分析最近一段时间的日志：

  ```shell
  # 在线分析最近一小时的日志，该指令执行的时候会从远程主机上拉取最近一小时的日志进行分析
  obdiag analyze queue --tenant=testA --since 1h


  # 在线分析最近 30 分钟的日志，该指令执行的时候会从远程主机上拉取最近 30 分钟的日志进行分析
  obdiag analyze queue --tenant=testA --since 30m
  ```
