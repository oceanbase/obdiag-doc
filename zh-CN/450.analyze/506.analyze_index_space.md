# 索引空间分析使用说明

obdiag analyze index\_space 可以一键分析已创建索引和未创建索引（指定索引列）的空间大小，在创建索引前分析即将创建索引的空间大小对于预防磁盘空间报警非常有帮助。

## 使用说明

```Plain Text
obdiag analyze index_space [option]
```

选项说明如下：

|      选项名      | 是否必选 | 数据类型 |  默认值  |                       说明                       |
| ---------------- | -------- | -------- | -------- | ------------------------------------------------ |
| \--tenant\_name  | 是       | string   | 默认为空 | 租户名称                                         |
| \--table\_name   | 是       | string   | 默认为空 | 表名称                                           |
| \--index\_name   | 否       | string   | 默认为空 | 索引名称                                         |
| \--column\_names | 否       | string   | 默认为空 | 列名称，指定多列用逗号分隔，例如：`col1,col2,col3` |
| -c | 否    | string |   `~/.obdiag/config.yml`           | 配置文件路径。     |
| --inner_config | 否    | string |   默认为空           | obdiag 自用的配置。     |
| --config | 否    | string |   默认为空           | 需被 obdiag 诊断的集群的配置，固定样式：--config key1=value1 --config key2=value2。  <main id="notice" type='explain'><h4>说明</h4><p>支持通过该选项配置的参数可参见 <a href="../300.obdiag-config-guide.md">obdiag 配置</a>。</p></main>     |
| --config_password     | 否    | string | 默认为空     | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。 <main id="notice" type='explain'><h4>说明</h4><p>详情可参见 <a href="../too/801.crypto_config.md">配置文件加密</a>。</p></main>      |

## 使用示例

* 分析已存在索引空间大小

  ```shell
  $ obdiag analyze index_space --tenant_name=test --table_name=student --index_name=name_index
  ```
  
  输出如下：
  
  ```shell
  analyze_index_space start ...
  start query estimated_table_data_size, please wait some minutes... ok
  +--------------------------------------------------------------------+

  +--------------+------+-----------------------+----------------------+
  |      ip      | port | estimated_index_space | available_disk_space |
  +--------------+------+-----------------------+----------------------+
  | 10.10.10.1   | 2882 |        2.57 KB        |       55.07 GB       |
  | 10.10.10.3   | 2882 |        2.57 KB        |       55.07 GB       |
  | 10.10.10.2   | 2882 |        3.50 KB        |       54.98 GB       |
  +--------------+------+-----------------------+----------------------+
  Trace ID: 9cbf48b0-6a9f-11ef-82ec-000c2934fb31

  ```

  $ obdiag analyze index_space --tenant_name=CHAT_BI --table_name=student --column_names=name
