# 合并状态展示

本文适用于独立部署 obdiag 的场景，可以一键展示 OceanBase 数据库的合并状态、进度、诊断信息和建议。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该场景仅支持 OceanBase 数据库 V4.0.0.0 及以上版本。</p>
</main>

## 使用说明

```shell
obdiag display scene run --scene=observer.compaction [options]
```

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| -c | 否    | string |   `~/.obdiag/config.yml`           | 配置文件路径。     |
| --inner_config | 否    | string |   默认为空           | obdiag 自用的配置。     |
| --config | 否    | string |   默认为空           | 需被 obdiag 诊断的集群的配置，固定样式：`--config key1=value1 --config key2=value2`。  <main id="notice" type='explain'><h4>说明</h4><p>支持通过该选项配置的参数可参见 <a href="../300.obdiag-config-guide.md">obdiag 配置</a>。</p></main>     |
| --config_password     | 否    | string | 默认为空     | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。 <main id="notice" type='explain'><h4>说明</h4><p>详情可参见 <a href="../800.tool/801.crypto_config.md">配置文件加密</a>。</p></main>      |

## 使用示例

### 方式一：无配置文件使用（开箱即用）

```shell
obdiag display scene run --scene=observer.compaction \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=***
```

### 方式二：有配置文件使用

需要确保已经在 obdiag 配置文件 <code>config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 [obdiag 配置](../300.obdiag-config-guide.md)。

```shell
obdiag display scene run --scene=observer.compaction
```

## 展示内容

该场景会展示以下四类合并相关信息。

### Major Compaction 状态

展示所有租户的 Major Compaction 状态，数据来源于 [CDB_OB_MAJOR_COMPACTION](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004477602) 视图，包含以下信息：

- `TENANT_ID`：租户 ID
- `FROZEN_SCN`：冻结版本号
- `GLOBAL_BROADCAST_SCN`：全局广播的版本号
- `LAST_SCN`：上次完成合并的版本号
- `LAST_FINISH_TIME`：上次合并完成时间
- `START_TIME`：本次合并开始时间
- `STATUS`：合并状态
- `IS_ERROR`：是否出错
- `IS_SUSPENDED`：是否暂停
- `INFO`：附加信息

### 合并进度

展示正在进行中的合并进度，数据来源于 [GV$OB_COMPACTION_PROGRESS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004477893) 视图，包含以下信息：

- `TENANT_ID`：租户 ID
- `SVR_IP`：服务器 IP
- `SVR_PORT`：服务器端口
- `ZONE`：Zone 名称
- `COMPACTION_SCN`：合并版本号
- `STATUS`：状态
- `TOTAL_TABLET_COUNT`：总 Tablet 数量
- `UNFINISHED_TABLET_COUNT`：未完成 Tablet 数量
- `DATA_SIZE_GB`：总数据大小（GB）
- `UNFINISHED_DATA_SIZE_GB`：未完成数据大小（GB）
- `START_TIME`：开始时间
- `ESTIMATED_FINISH_TIME`：预计完成时间

### 合并诊断信息

展示失败或正在运行中的合并任务诊断信息，数据来源于 `__all_virtual_compaction_diagnose_info` 视图，包含以下信息：

- `tenant_id`：租户 ID
- `svr_ip`：服务器 IP
- `svr_port`：服务器端口
- `ls_id`：日志流 ID
- `tablet_id`：Tablet ID
- `type`：类型
- `status`：状态
- `create_time`：创建时间
- `diagnose_info`：诊断信息

### 合并建议

展示系统给出的合并优化建议，数据来源于 [GV$OB_COMPACTION_SUGGESTIONS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004477865) 视图，包含以下信息：

- `TENANT_ID`：租户 ID
- `SVR_IP`：服务器 IP
- `SVR_PORT`：服务器端口
- `TYPE`：类型
- `LS_ID`：日志流 ID
- `TABLET_ID`：Tablet ID
- `START_TIME`：开始时间
- `FINISH_TIME`：完成时间
- `SUGGESTION`：建议内容
