# clog 日志量/容量统计

本文适用于独立部署 obdiag 的场景，可以一键展示 OceanBase 数据库各节点、各租户的 clog/日志盘使用情况。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该场景仅支持 OceanBase 数据库 V4.0.0.0 及以上版本。</p>
</main>

## 使用说明

```shell
obdiag display scene run --scene=observer.clog_volume_statistics [options]
```

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| -c | 否    | string |   `~/.obdiag/config.yml`           | 配置文件路径。     |
| --inner_config | 否    | string |   默认为空           | obdiag 自用的配置。     |
| --config | 否    | string |   默认为空           | 需被 obdiag 诊断的集群的配置，固定样式：`--config key1=value1 --config key2=value2`。  <main id="notice" type='explain'><h4>说明</h4><p>支持通过该选项配置的参数可参见 <a href="../300.obdiag-config-guide.md">obdiag 配置</a>。</p></main>     |
| --config_password     | 否    | string | 默认为空     | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。 <main id="notice" type='explain'><h4>说明</h4><p>详情可参见 <a href="../800.tool/801.crypto_config.md">配置文件加密</a>。</p></main>      |

## 使用示例

### 方式一：无配置文件使用（开箱即用）

```shell
obdiag display scene run --scene=observer.clog_volume_statistics \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=***
```

### 方式二：有配置文件使用

需要确保已经在 obdiag 配置文件 <code>config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 [obdiag 配置](../300.obdiag-config-guide.md)。

```shell
obdiag display scene run --scene=observer.clog_volume_statistics
```

## 展示内容

该场景会展示以下两类 clog 日志盘使用情况。

### 服务器级别日志盘（clog）使用情况

展示各节点的日志盘容量和使用情况，数据来源于 [GV$OB_SERVERS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004477958) 视图，包含以下信息：

- `SVR_IP`：服务器 IP
- `SVR_PORT`：服务器端口
- `ZONE`：Zone 名称
- `LOG_DISK_CAPACITY_GB`：日志盘总容量（GB）
- `LOG_DISK_ASSIGNED_GB`：已分配的日志盘容量（GB）
- `LOG_DISK_IN_USE_GB`：已使用的日志盘容量（GB）
- `USE_PCT`：使用率（百分比）

### 租户级别日志盘（clog）使用情况

展示各租户在各节点上的日志盘使用情况，数据来源于 [GV$OB_UNITS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004477911) 视图，包含以下信息：

- `TENANT_NAME`：租户名称
- `SVR_IP`：服务器 IP
- `SVR_PORT`：服务器端口
- `LOG_DISK_SIZE_GB`：分配的日志盘大小（GB）
- `LOG_DISK_IN_USE_GB`：已使用的日志盘大小（GB）
- `USE_PCT`：使用率（百分比）

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该场景展示的是当前时刻的快照数据。如需统计规定时间范围内的日志盘使用变化，可分别在时段起止时刻各执行一次本场景，然后对比两次执行的结果。</p>
</main>
