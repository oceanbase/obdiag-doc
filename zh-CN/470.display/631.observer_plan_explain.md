# 实际执行计划算子信息洞察

本文适用于独立部署 obdiag 的场景，可以一键执行将实际执行计划算子信息展示出来。

## 使用说明

```shell
obdiag display scene run --scene=observer.plan_explain [options]
```

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| -c | 否    | string |   `~/.obdiag/config.yml`           | 配置文件路径。     |
| --inner_config | 否    | string |   默认为空           | obdiag 自用的配置。     |
| --config | 否    | string |   默认为空           | 需被 obdiag 诊断的集群的配置，固定样式：--config key1=value1 --config key2=value2。  <main id="notice" type='explain'><h4>说明</h4><p>支持通过该选项配置的参数可参见 <a href="../300.obdiag-config-guide.md">obdiag 配置</a>。</p></main>     |
| --env | 是    | string |   默认为空           | obdiag display 所需的额外参数，此处用于设置实际执行计划的相关信息。固定样式：`--env svr_ip=${IP} --env svr_port=${PORT} --env tenant_id=${TENANT_ID} --env plan_id=${PLAN_ID}`。 |
| --config_password     | 否    | string | 默认为空     | obdiag 使用加密的配置文件时，需通过该选项传入对应的密码。 <main id="notice" type='explain'><h4>说明</h4><p>详情可参见 <a href="../too/801.crypto_config.md">配置文件加密</a>。</p></main>      |

## 使用示例

### 步骤一：获取命令所需的 env

```sql
-- OceanBase Database version >= 4.0, 
select svr_ip, svr_port, tenant_id, plan_id from gv$ob_sql_audit where trace_id='xxxxx';

-- OceanBase Database version < 4.0
select svr_ip, svr_port, tenant_id, plan_id from gv$sql_audit where trace_id='xxxxx';
```

以 OceanBase 数据库版本大于 4.0，`trace_id` 是 `YF2A0BA2DA7E-00062C1FC9CFFF3F-0-0` 为例，命令如下：

```shell
obclient [oceanbase]> select svr_ip, svr_port, tenant_id, plan_id from gv$ob_sql_audit where trace_id='YF2A0BA2DA7E-00062C1FC9CFFF3F-0-0';
```

输出如下：

```shell
+----------------+----------+-----------+---------+
| svr_ip         | svr_port | tenant_id | plan_id |
+----------------+----------+-----------+---------+
| 10.10.10.1     |     2882 |         1 |    1635 |
+----------------+----------+-----------+---------+
```

### 步骤二：查询实际执行计划算子

* 无配置文件使用（开箱即用）

  ```shell
  obdiag display scene run --scene=observer.plan_explain --env svr_ip=10.10.10.1 --env svr_port=2882 --env tenant_id=1 --env plan_id=1635 \
      --config db_host=xx.xx.xx.xx \
      --config db_port=xxxx \
      --config tenant_sys.user=root@sys \
      --config tenant_sys.password=***
  ```

* 有配置文件使用

  需要确保已经在 obdiag 配置文件 <code>config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 [obdiag 配置](../300.obdiag-config-guide.md)。

  ```shell
  obdiag display scene run --scene=observer.plan_explain --env svr_ip=10.10.10.1 --env svr_port=2882 --env tenant_id=1 --env plan_id=1635
  ```
