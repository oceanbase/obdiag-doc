# 集群 topsql 信息展示

本文适用于独立部署 obdiag 的场景，可以一键执行将集群的 topsql 信息在终端显示。

## 使用说明

```shell
obdiag display scene run --scene=observer.topsql [options]
```

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| -c | 否    | string |   `~/.obdiag/config.yml`           | 配置文件路径。     |
| --inner_config | 否    | string |   默认为空           | obdiag 自用的配置。     |
| --config | 否    | string |   默认为空           | 需被 obdiag 诊断的集群的配置，固定样式：`--config key1=value1 --config key2=value2`。     |
| --env | 是    | string |   默认为空           | obdiag display 所需的额外参数，固定样式：`--env db_connect='-h127.0.0.1 -P2881 -utest@test -p****** -Dtest' --env mtime=10`。    |

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul><li>
  <p>参数 <code>--env</code> 中 <code>db_connect='-h127.0.0.1 -P2881 -utest@test -p****** -Dxxxx'</code> 是业务租户的连接串信息是非必填项。 </p>
  </li><li>
  <p>参数 <code>--env</code> 中 <code>mtime</code> 是只查看最新多长时间的 topsql，单位分钟。 </p>
  </li></ul>
</main>

## 使用示例

### 方式一：无配置文件使用（开箱即用）

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本节命令中使用的详细配置介绍可参见 <a href="../300.obdiag-config-guide.md">obdiag 配置</a>。</p>
</main>

```shell
# 通过额外传递 --env 参数来指定查询的租户连接串 10 分钟的 topsql
$ obdiag display scene run --scene=observer.topsql --env db_connect='-h127.0.0.1 -P2881 -utest@test -p****** -Dtest' --env mtime=10 \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=***

# 不通过额外传递 --env 参数来指定查询的租户连接串，默认用 sys 租户来查所有租户的 topsql
obdiag display scene run --scene=observer.topsql --env mtime=10 \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=***
```

### 方式二：有配置文件使用

需要确保已经在 obdiag 配置文件 <code>config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 [obdiag 配置](../300.obdiag-config-guide.md)。

```shell
# 通过额外传递 --env 参数来指定查询的租户连接串
obdiag display scene run --scene=observer.topsql --env db_connect='-h127.0.0.1 -P2881 -utest@test -p****** -Dtest' --env mtime=10

# 不通过额外传递 --env 参数来指定查询的租户连接串，默认用 sys 租户来查所有租户的 topsql
obdiag display scene run --scene=observer.topsql --env mtime=10
```
