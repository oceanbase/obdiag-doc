# 集群事件信息洞察

本文适用于独立部署 obdiag 的场景，可以一键执行将集群的 event 信息在终端显示。

## 使用说明

```shell
obdiag display scene run --scene=observer.event [options]
```

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| -c | 否    | string |   `~/.obdiag/config.yml`           | 配置文件路径。     |
| --inner_config | 否    | string |   默认为空           | obdiag 自用的配置。     |
| --config | 否    | string |   默认为空           | 需被 obdiag 诊断的集群的配置，固定样式：`--config key1=value1 --config key2=value2`。     |
| --env | 否    | string |   默认为空           | obdiag display 所需的额外参数，固定样式：`---env tenant_name=test`。     |

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>可选参数 <code>--env</code> 中 <code>tenant_name</code> 需配置为待展示 event 信息的业务租户名。 </p>
</main>

## 使用示例

### 方式一：无配置文件使用（开箱即用）

```shell
obdiag display scene run --scene=observer.event --env tenant_name=test \
    --config db_host=xx.xx.xx.xx \
    --config db_port=xxxx \
    --config tenant_sys.user=root@sys \
    --config tenant_sys.password=***
```

### 方式二：有配置文件使用

需要确保已经在 obdiag 配置文件 <code>config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 [obdiag 配置](../300.obdiag-config-guide.md)。

```shell
obdiag display scene run --scene=observer.event --env tenant_name=test
```
