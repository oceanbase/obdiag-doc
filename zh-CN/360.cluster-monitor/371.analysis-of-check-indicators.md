# 关于集群巡检指标的详解

本文对 obdiag 部分巡检指标来源进行解释。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本节中所提到的 <code>issue #xx</code> 指 obdiag 项目的 issue 编号。</p>
</main>

## OBProxy 检查项

| 检查项名称 | 检查项描述 |
|-----------|-----------|
| version.bad_version | 检查 OBProxy 版本是否为不建议使用版本。一些版本的 OBProxy 存在缺陷，不建议使用。 |
| version.old_version | 检查 OBProxy 版本是否为旧版本。一些旧版本的 OBProxy 不再支持，不推荐使用。 |
| parameter.request_buffer_length | 检查 OBProxy 配置项 [request_buffer_length](https://www.oceanbase.com/docs/common-odp-doc-cn-1000000003575451) 是否为默认值。 |
| parameter.work_thread_num | 检查 OBProxy 配置项 [work_thread_num](https://www.oceanbase.com/docs/common-odp-doc-cn-1000000003575503) 的值，防止线程耗尽问题。来源可参见 GitHub [issue #1019](https://github.com/oceanbase/obdiag/issues/1019)。 |

### 租户检查项

| 检查项名称 | 检查项描述 |
|-----------|-----------|
| tenant.tenant_threshold | 检查租户线程利用率，当超过 95% 阈值时告警。来源可参见 GitHub [issue #963](https://github.com/oceanbase/obdiag/issues/963)。|
| tenant.tenant_locality_consistency_check | 检查租户地域一致性与日志流成员数量，确保租户可用性。来源可参见 GitHub [issue #1048](https://github.com/oceanbase/obdiag/issues/1048)。 |
| tenant.max_stale_time_for_weak_consistency | 检查 [max_stale_time_for_weak_consistency](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003979795) 配置项是否为默认值。来源可参见 GitHub [issue #840](https://github.com/oceanbase/obdiag/issues/840)。 |
| tenant.tenant_min_resource | 检查租户资源池配置，如果 CPU 或内存少于 2C4G，将进行报告。 |
| tenant.parameters_default | 检查所有配置项是否均为默认值。来源可参见 GitHub [issue #850](https://github.com/oceanbase/obdiag/issues/850)。 |
| tenant.macroblock_utilization_rate_tenant | 检查 OceanBase 集群中所有租户的实际数据量与实际磁盘使用率的比例是否在合理范围内。OceanBase 数据库以宏块存储数据，每个宏块可能未完全利用以提高效率。如果实际数据量与实际磁盘使用率的比例过低，应执行全量合并以提高磁盘利用率。来源可参见 GitHub [issue #847](https://github.com/oceanbase/obdiag/issues/847)。 |
| tenant.writing_throttling_trigger_percentage | 检查 [writing_throttling_trigger_percentage](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003979793) 是否被配置设置为 `100`，如被配置为 `100` 将关闭写速度限制，导致 MemStore 爆炸。来源可参见 GitHub [issue #758](https://github.com/oceanbase/obdiag/issues/758)。  |
