
# 分析变量

obdiag analyze variable diff 可以一键分析 OceanBase 在线集群变量和之前相比是否变更了，这非常有助于排查变量变更带来的问题。


需要确保已经在 obdiag 配置文件 <code>config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见[obdiag 配置](../300.obdiag-config-guide.md)

## 使用说明

```shell
obdiag analyze variable diff [option]
```

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| --file | 是    | string |   默认为空              | 传递的是之前某次执行的 `obdiag gather variable` 的存档文件|
| --store_dir | 否    | string |   默认为命令执行的当前路径              | 存储结果的本地路径。 |
| -c | 否    | string |   `~/.obdiag/config.yml `           | 配置文件路径     |

## 使用示例

```bash
obdiag analyze variable diff

# 通过文件路径指定之前某次执行的 obdiag gather variable 存档文件来分析变量变更
obdiag analyze variable diff --file=./gather_variables/obcluster_variables_20240808144053.csv
```
