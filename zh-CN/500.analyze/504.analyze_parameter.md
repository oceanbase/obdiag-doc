
# 参数分析(不同 observer 上的参数差异)

使用该命令可以一键分析 OceanBase 在线集群参数在各个 observer 上的差异，如果有差异将会输出差异报告，当然也支持离线文件传入分析集群参数在各个 observer 上的差异。这非常有助于排查参数在不同 observer 上差异带来的问题。


<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>需要确保已经在 obdiag 配置文件 <code>config.yml</code> 中配置好需要收集节点的登录信息。相关的详细配置介绍，参见 <a href="./300.obdiag-config-guide.md">obdiag 配置</a>。</p>
</main>

## 使用说明

```shell
obdiag analyze parameter diff [option]
```

选项说明如下：

| 选项名                                                   | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| --file | 否    | string |   默认为空              | observer 版本低于 V4.2.2 时此参数文件必须要填写，传递的是之前某次执行的 `obdiag gather parameter` 的存档文件|
| --store_dir | 否    | string |   默认为命令执行的当前路径              | 存储结果的本地路径。 |
| -c | 否    | string |   `~/.obdiag/config.yml `           | 配置文件路径     |

## 使用示例

```shell
obdiag analyze parameter diff

# 离线文件传入分析集群参数在各个 observer 上的差异
obdiag analyze parameter diff --file=/home/admin/gather_parameters/obcluster_parameters_20240808202546.csv
```
